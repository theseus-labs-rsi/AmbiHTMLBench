# RC1 Validation Claim Note

The final unbiased 30-pair blind audit does not demonstrate higher human-agreement accuracy for the RC1 Prompt than the original Prompt. RC1 is retained because it implements the corrected subjective-evaluation specification and integrates with the final reliability/ranking system.

When presenting RC1, attribute the validated gains primarily to:
- corrected benchmark specification;
- dual-orientation reliability measurement;
- explicit reliability/perceptual TIE semantics;
- order-invariant Batch Bradley–Terry rating;
- balanced scheduling and uncertainty reporting;
- robust engineering and reproducibility.

Do not claim prompt-level human-accuracy superiority.
