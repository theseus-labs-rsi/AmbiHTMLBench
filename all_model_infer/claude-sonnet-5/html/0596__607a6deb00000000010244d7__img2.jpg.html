§ 4.3 体内物质的运输
血液循环系统 { 血液 心脏 血管
一. 血液(约为体重的7% ~ 8%)

1. 血液 {
血浆(55%) { 水、无机盐、葡萄糖、蛋白质[?]等 运载血细胞，运输养料和废物
血细胞(45%) { 红细胞 白细胞 血小板

— 一次失血超过体内血量的30%，就会危及生命

2. 红细胞
(1)特点：没有细胞核，呈两面凹的圆盘状 增加表面积，携氧量
(2)数量：正常男性平均为500万个/mm³
正常女性平均为420万个/mm³
(3)功能：运输氧和部分二氧化碳
(4)红细胞的特性：在氧浓度高的地方容易与氧结合，在氧浓度低的地方容易与氧分离

3. 白细胞
(1)特点：数量少，有细胞核，体积比红细胞大
(2)数量：一般在4000~10000个/mm³血液范围内波动
(3)功能：吞噬侵入人体内的细菌，保护人体免受感染
(4)功能???：本体防御和保护和病菌[?]，主要能做变形运动过血管壁，并有免疫作用
(数量少[每红细胞数量约为1:600]但种类多)

4. 血小板
(1)特点：形状不规则，无细胞核，很小
(2)直径2~4μm，体积仅次于红细胞1[?]，是血液中最小的有形成分
(3)数量：正常成人为15~30万个/mm³
(4)功能：加速血液凝固，防止大量出血及阻止细菌入侵

5. 人体血细胞数量变化及症状
红细胞　　若数目减少，就是贫血
白细胞　　若数目增多，就是身体有炎症
血小板　　若数目减少，不能凝血

6. 血细胞的寿命
血细胞都有一定的寿命，红细胞有寿命约为120天，大约60天后红细胞更换一半，红骨髓具有造血[illegible]
