金陵十二钗正册判词
[Illustration: 立像人物，持笛，左侧]
林黛玉（情情） 可叹停机德，
堪怜咏絮才。
玉带林中挂，
金簪雪里埋。
[Illustration: 立像人物，持扇，左侧]
薛宝钗（无情） 可叹停机德，
堪怜咏絮才。
玉带林中挂，
金簪雪里埋。
[Illustration: 立像人物，橙衣，左侧]
王熙凤（情雕） 凡鸟偏从末世来，
都知爱慕此生才。
一从二令三人木，
哭向金陵事更哀。
[Illustration: 立像人物，黄衣，左侧]
贾元春（情尊） 二十年来辨是非，
榴花开处照宫闱。
三春争及初春景，
虎兔相逢大梦归。
[Illustration: 立像人物，持扇，左侧]
贾迎春（情桃） 子系中山狼，
得志便猖狂。
金闺花柳质，
一载赴黄粱。
[Illustration: 立像人物，红衣，左侧]
贾探春（情敏） 才自精明志自高，
生于末世运偏消。
清明涕送江边望，
千里东风一梦遥。
[Illustration: 立像人物，黄衣，左侧]
贾惜春（情冷） 堪破三春景不长，
缁衣顿改昔年装。
可怜绣户侯门女，
独卧青灯古佛旁。
[Illustration: 立像人物，红衣，左侧]
史湘云（情憨） 富贵又何为，
襁褓之间父母违。
展眼吊斜晖，
湘江水逝楚云飞。
[Illustration: 立像人物，紫衣，左侧]
秦可卿（情尊） 情天情海幻情身，
情既相逢必主淫。
漫言不肖皆荣出，
造衅开端实在宁。
[Illustration: 立像人物，绿衣，左侧]
妙玉（情隐） 欲洁何曾洁？
云空未必空。
可怜金玉质，
终陷淖泥中。
[Illustration: 立像人物，粉裙，左侧]
贾巧姐（情缘） 势败休云贵，
家亡莫论亲。
偶因济刘氏，
巧得遇恩人。
[Illustration: 立像人物与小童，左侧]
李纨（情编） 桃李春风结子完，
到头谁似一盆兰。
如冰水好空相妒，
枉与他人作笑谈。
