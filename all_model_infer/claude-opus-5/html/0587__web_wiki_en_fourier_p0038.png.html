501 $\chi_{[0,1]}(|\mathbf{x}|)\left(1-|\mathbf{x}|^2\right)^{\delta}$ $\dfrac{\Gamma(\delta+1)}{\pi^{\delta}\,|\boldsymbol{\xi}|^{\gamma}} J_{\gamma}(2\pi|\boldsymbol{\xi}|)$ $2^{\delta}\,\dfrac{\Gamma(\delta+1)}{|\boldsymbol{\omega}|^{\gamma}} J_{\gamma}(|\boldsymbol{\omega}|)$ $\dfrac{\Gamma(\delta+1)}{\pi^{\delta}}\left|\dfrac{\boldsymbol{\omega}}{2\pi}\right|^{-\gamma} J_{\gamma}(|\boldsymbol{\omega}|)$ Here, $\gamma = \frac{n}{2} + \delta$.

The function $\chi_{[0,\ 1]}$ is the indicator function of the interval $[0,\ \ 1]$. The function $\Gamma(x)$ is the gamma function. The function $J_{\frac{n}{2}+\delta}$ is a Bessel function of the first kind, with order $\frac{n}{2} + \delta$. Taking $n = 2$ and $\delta = 0$ produces 402.[82]
502 $|\mathbf{x}|^{-\alpha}, \quad 0 < \operatorname{Re}\alpha < n$ $\dfrac{(2\pi)^{\alpha}}{c_{n,\alpha}}|\boldsymbol{\xi}|^{-(n-\alpha)}$ $\dfrac{(2\pi)^{\frac{n}{2}}}{c_{n,\alpha}}|\boldsymbol{\omega}|^{-(n-\alpha)}$ $\dfrac{(2\pi)^{n}}{c_{n,\alpha}}|\boldsymbol{\omega}|^{-(n-\alpha)}$ See Riesz potential, where the constant is given by $c_{n,\alpha} = \pi^{\frac{n}{2}} 2^{\alpha}\Gamma\left(\frac{\alpha}{2}\right)\big/\Gamma\left(\frac{n-\alpha}{2}\right).$ The formula also holds for all $\alpha \neq n,\, n+2,\, \ldots$ by analytic continuation, but then the function and its Fourier transforms need to be understood as suitably regularized tempered distributions (see Homogeneous distribution).[note 10]
