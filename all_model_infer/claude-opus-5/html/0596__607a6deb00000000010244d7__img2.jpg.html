§ 4-3 体内物质的运输

一. 血液(约为体重的 7%～8%)
1. 血液 {
血浆(55%) 水、无机盐、葡萄糖、蛋白质等 运载血细胞，运输养料和废物
血细胞(45%) {
红细胞
白细胞
血小板
一次失血超过体内血量的 30%，就会危及生命
2. 红细胞
(1)特点：数量最多，呈两面凹的圆盘状，增加表面积，携氧量
(2)数量：正常男性平均为 500 万个/mm3
正常女性平均为 420 万个/mm3
(3)功能：运输氧和部分二氧化碳
(4)成熟红细胞的特点，在氧浓度高的地方容易和氧结合，在氧浓度低的地方容易与氧分离
3. 白细胞
(1)特点：数量少，有细胞核，体积比红细胞大
(2)数量：一般为 4000～10000 个/mm3，血液范围内流动
(3)功能：吞噬侵入人体内的细菌，保护人体免受病害
(4)功能??? 机体防御和保护功能，主要是能做变形运动和吞噬运动，具有免疫功能
(数量少[与红细胞数量比约为1:600]但种类多)
4. 血小板
(1)特点：形状不规则，无细胞核，很小
直径约 2～4 μm，体积仅相当于红细胞的十[?]一，是血液中最小的有形成分
(2)数量：正常成人 10万～30万个/mm3
(3)功能：加速血液凝固，防止大量血液外流阻止细菌入侵
5. 人体血细胞数量变化及症状
红细胞 若数目减少，容易贫血
白细胞 若数目增多，容易身体有炎症
血小板 若数目减少，不能凝血
6. 血细胞的寿命
血细胞都有一定的寿命。红细胞寿命约为120天，大约60天后红细胞更换一半，红骨髓有造血功能
