列3程解题时,以“人车间距始终固定不变”为依据来建立等量关系.
例:
A步行速度为60米/分,A发现每隔15分钟就会有一辆1路公交车追上他,
而每隔10分钟就与一辆迎面开来的1路公交车相遇。求1路公交车间
隔发车的时间。
分析:无论是后面开来的,还是迎面开来的,都是1路公交车。即:车间距
始终不变。
① 从后面追来的”:人车同向,S追 = 车间距 = V追 × 七追发间隔
等量关系 → 相等 = (V车 − 60) × 15
= 15(V车 − 60)
② 迎面相遇的”,人车相向:S和 = 车间距 = V和 × 七相遇间隔
= (V车 + 60) × 10
= 10(V车 + 60)
解:设1路公交车的速度为x米/分。根据题意,得:
15(x − 60) = 10(x + 60)
15x − 900 = 10x + 600
15x − 10x = 600 + 900
5x = 1800
x = 300
即:1路公交车的速度为300米/分。
车间距:15×(300−60) = 3600 (米) 或 10×(300 + 60) = 3600(米)
根据“车间距 = V车 · 七发车间隔”可得:
七发车间隔 = 车间距 ÷ V车 = 3600 ÷ 300 = 12(分)
答:1路公交车的发车时间间隔为12分钟
