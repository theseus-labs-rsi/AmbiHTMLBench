4. 两个 $n$阶方阵乘积的行列式等于行列式的乘积

$|AB| = |A|\,|B|$

✿ 设$A_1,\,A_2\cdots,\ A_m$ 都为$n$阶方阵，则$|A_1A_2\cdots A_m| = |A_1|\,|A_2|\cdots|A_m|$

推论：设 $A$ 为 $n$阶方阵，则 $|kA| = k^{\,n}\,|A|$

例：$A,B$为$n$阶方阵，$|A| = a \neq 0$，若 $AB + 2E = 0$ 求$|B|$

$|AB| = |A||B| = a\,|B| = |-2E| = (-2)^{n}$

$\therefore\ |B| = (-2)^{n}\cdot\dfrac{1}{a}$

5. 转置矩阵记为 $A^{T}$

☆定理$(A^{T})^{T} = A$$(A+B)^{T} = A^{T} + B^{T}$$|A| = |A^{T}|$

$(kA)^{T} = kA^{T}$$(AB)^{T} = B^{T}A^{T}$

若 $A^{T} = A$ ，则 $A$为 对称矩阵 ，若 $A^{T} = -A$，则 $A$为 反对称矩阵
