同步解析与测评
数学  五年级  下册
第 2 课时    第 1 课时练习课
1. 填一填。
(1) $\frac{3}{4} + \frac{2}{5} = ($ $\frac{2}{5}$ $) + \frac{3}{4}$，应用了( 加法交换 )律。
(2) $\frac{1}{8} + \frac{3}{8} + \frac{5}{8} = \frac{1}{8} + (\frac{3}{8} + \frac{5}{8})$，应用了( 加法结合 )律。
(3) $1 - \frac{4}{15} - \frac{7}{15} = 1 - (\frac{4}{15} + \frac{7}{15})$，应用了( 减法的性质 )。
2. 在 $\bigcirc$ 里填上适当的运算符号。
(1) $\frac{3}{8} + \frac{4}{9} + \frac{5}{9} = \frac{3}{8} + (\frac{4}{9} \ \text{+}\ \frac{5}{9})$
(2) $\frac{3}{8} + \frac{4}{9} - \frac{4}{9} = \frac{3}{8} + (\frac{4}{9} \ \text{−}\ \frac{4}{9})$
(3) $\frac{8}{7} - \frac{5}{9} - \frac{4}{9} = \frac{8}{7} - (\frac{5}{9} \ \text{+}\ \frac{4}{9})$
(4) $\frac{8}{7} - \frac{4}{9} + \frac{4}{9} = \frac{8}{7} - (\frac{4}{9} \ \text{−}\ \frac{4}{9})$
3. 选择合适的方法进行计算。
$\frac{3}{4} + \frac{1}{3} - \frac{5}{6}$
$= \frac{9}{12} + \frac{4}{12} - \frac{10}{12}$
$= \frac{3}{12} = \frac{1}{4}$
$\frac{5}{8} + (\frac{3}{4} - \frac{1}{6})$
$= \frac{15}{24} + \frac{18}{24} - \frac{4}{24}$
$= \frac{29}{24}$
$\frac{2}{3} - (\frac{5}{6} - \frac{5}{8})$
$= \frac{16}{24} - (\frac{20}{24} - \frac{15}{24})$
$= \frac{16}{24} - \frac{5}{24}$
$= \frac{11}{24}$
$\frac{7}{9} + \frac{5}{7} + \frac{5}{9}$
$= \frac{12}{9} + \frac{5}{7}$
$= \frac{4}{3} + \frac{5}{7}$
$= \frac{28}{21} + \frac{15}{21} = \frac{43}{21}$
$1 - \frac{3}{4} - \frac{1}{20}$
$= 1 - (\frac{15}{20} + \frac{1}{20})$
$= 1 - \frac{16}{20}$
$= \frac{4}{20} = \frac{1}{5}$
$\frac{5}{8} + \frac{5}{7} + \frac{3}{8} - \frac{3}{14}$
$= (\frac{5}{8} + \frac{3}{8}) + (\frac{5}{7} - \frac{3}{14})$
$= 1 + (\frac{10}{14} - \frac{3}{14})$
$= 1 + \frac{7}{14} = 1 + \frac{1}{2}$
$= 1\frac{1}{2}$
4. 计算下面图形的周长。
① $\frac{1}{2} + \frac{4}{5} + \frac{7}{10}$
$= \frac{5}{10} + \frac{8}{10} + \frac{7}{10}$
$= \frac{20}{10} = 2(\text{dm})$
② $\frac{7}{12} + \frac{7}{12} + \frac{1}{3} + \frac{1}{3}$
$= \frac{14}{12} + \frac{2}{3}$
$= \frac{7}{6} + \frac{4}{6} = \frac{11}{6}(\text{m})$
5. 周末，五(1)班有 $\frac{2}{7}$ 的同学到郊外劳动，有 $\frac{2}{5}$ 的同学到图书馆读书，还有 $\frac{11}{35}$ 的同学留在家中。留在家中的同学比出门的同学多还是少？多或少几分之几？
$\frac{2}{7} + \frac{2}{5} = \frac{24}{35} \quad \frac{11}{35} < \frac{24}{35}$
$\frac{24}{35} - \frac{11}{35} = \frac{13}{35}$
6. 有一个装满水的水池，若第一次放出一池水的 $\frac{3}{8}$，第二次放出一池水的 $\frac{1}{4}$，第三次又注入一池水的 $\frac{4}{7}$。现在池子里的水占池子的几分之几？
$1 - \frac{3}{8} - \frac{1}{4} + \frac{4}{7} = \frac{53}{56}$
