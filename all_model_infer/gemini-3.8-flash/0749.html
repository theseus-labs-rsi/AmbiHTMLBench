◇ 令 $F(a) = \ln a - \dfrac{a-1}{a+1}$; $F(1) = 0$
$$F'(a) = \frac{1}{a} - \frac{2}{(a+1)^2} = \frac{a^2+1}{a(a+1)^2} > 0$$
$\therefore F(a)$ 在 $(0, +\infty)$ 上递增, $a = 1$

由(1)知, $f(x)$ 在 $(-\infty, 0) \searrow, (0, +\infty) \nearrow$;
$g(x)$ 在 $(0, 1) \searrow, (1, +\infty) \nearrow$
要有三个交点则必是如右所示, 考场中可用零
点存在定理说明一下, 两函数在 $(0, 1)$ 上有一
个交点 $x_0$.
由题知:
$g(x_1) = g(x_0) = f(x_0) = f(x_2)$
$e^{x_1} - x_1 = e^{x_0} - x_0 = x_0 - \ln x_0 = x_2 - \ln x_2 \cdots *$
$x_1 < 0, 0 < x_0 < 1, x_2 > 1$
$e^{x_1} - x_1 = e^{\ln x_0} - \ln x_0 \text{ ; } x_2 - \ln x_2 = e^{x_0} - \ln e^{x_0} \text{ , , } e^{x_0} > 1$
即 $g(x_1) = g(\ln x_0),\, x_1, \ln x_0 < 0 \Rightarrow x_1 = \ln x_0$; 同理 $f(x_2) = f(e^{x_0}) \Rightarrow x_2 = e^{x_0}$
$x_1 + x_2 = \ln x_0 + e^{x_0} = 2x_0$ 由 $(*)$ 式可得。
