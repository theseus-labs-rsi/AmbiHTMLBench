Here, $\gamma=\frac n2+\delta$.

The function $\chi_{[0,\,1]}$ is the indicator function of the interval $[0,\,1]$. The function $\Gamma(x)$ is the gamma function. The function $J_{\frac n2+\delta}$ is a Bessel

function of the first kind,

with order $\displaystyle\frac n2+\delta$. Taking

$n=2$ and $\delta=0$ produces 402.[82]

$c_{n,\alpha}=\pi^{\frac n2}2^\alpha\Gamma\left(\frac\alpha2\right)/\Gamma\left(\frac{n-\alpha}{2}\right)$.
The formula also holds for all $\alpha\ne n,n+2,\ldots$ by analytic continuation, but then the function and its Fourier transforms need to be understood as suitably regularized tempered distributions (see Homogeneous distribution).[note 10]
