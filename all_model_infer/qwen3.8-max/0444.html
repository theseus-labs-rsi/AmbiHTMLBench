1.填一填。
(1) $\frac{3}{4} + \frac{2}{5} = ($$\frac{2}{5}$$) + \frac{3}{4}$，应用了
(加法交换)律。
(2) $\frac{1}{6} + \frac{3}{8} + \frac{5}{8} = \frac{1}{6} + (\frac{3}{8} + \frac{5}{8})$，应用
了(加法结合)律。
(3) $1 - \frac{4}{15} - \frac{7}{15} = 1 - (\frac{4}{15} + \frac{7}{15})$，应用了
(减法的性质)。
2.在 里填上适当的运算符号。
(1) $\frac{3}{8} + \frac{4}{9} + \frac{5}{9} = \frac{3}{8} + (\frac{4}{9}$ + $\frac{5}{9})$
(2) $\frac{3}{8} + \frac{4}{9} - \frac{4}{9} = \frac{3}{8} + (\frac{4}{9}$ - $\frac{4}{9})$
(3) $\frac{8}{7} - \frac{5}{9} - \frac{4}{9} = \frac{8}{7} - (\frac{5}{9}$ + $\frac{4}{9})$
(4) $\frac{8}{7} - \frac{4}{9} + \frac{4}{9} = \frac{8}{7} - (\frac{4}{9}$ - $\frac{4}{9})$
3.选择合适的方法进行计算。
$\frac{3}{4} + \frac{1}{3} - \frac{5}{6}$
$= \frac{9}{12} + \frac{4}{12} - \frac{10}{12}$
$= \frac{13}{12} - \frac{10}{12}$
$= \frac{3}{12} = \frac{1}{4}$
$\frac{5}{8} + (\frac{3}{4} - \frac{1}{6})$
$= \frac{15}{24} + \frac{18}{24} - \frac{4}{24}$
$= \frac{29}{24}$
$\frac{2}{3} - (\frac{5}{6} - \frac{5}{8})$
$= \frac{16}{24} - (\frac{20}{24} - \frac{15}{24})$
$= \frac{16}{24} - \frac{5}{24}$
$= \frac{11}{24}$
$\frac{2}{9} + \frac{5}{7} + \frac{5}{9}$
$= \frac{2}{9} + \frac{5}{9} + \frac{5}{7}$
$= \frac{7}{9} + \frac{5}{7}$
$= \frac{49}{63} + \frac{45}{63} = \frac{94}{63} = 1\frac{31}{63}$
$1 - \frac{3}{4} - \frac{1}{20}$
$= 1 - (\frac{15}{20} + \frac{1}{20})$
$= 1 - \frac{16}{20}$
$= \frac{4}{20} = \frac{1}{5}$
$\frac{5}{8} + \frac{5}{7} + \frac{3}{8} - \frac{3}{14}$
$= (\frac{5}{8} + \frac{3}{8}) + (\frac{5}{7} - \frac{3}{14})$
$= 1 + (\frac{10}{14} - \frac{3}{14})$
$= 1 + \frac{7}{14}$
$= 1\frac{1}{2}$
