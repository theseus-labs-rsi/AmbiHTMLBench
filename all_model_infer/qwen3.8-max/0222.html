Introduction

A novel Parallelised Bayesian Inference of the Multispecies Coalescent with new MCMC proposals has been implemented in the open-source BEAST 2 platform as the StarBeast3 package. This new approach avoids biases, such as being an inconsistent estimator of the tree topology. Furthermore, it explores the state space much more efficiently, allowing the handle of data sets one and a half orders of magnitude larger than StarBeast2 and more than two orders faster than *BEAST.

Our goal was to establish the correct implementation of StarBeast3 by testing different numbers of taxa and genes.

Key words: multispecies coalescent; BEAST 2; phylogenetics; bayesian inference; high performance; adaptive; parallelisation.

Methods

We performed well calibration studies by simulating alignments using parameters directly sampled from the prior distribution, and then we inferred the posterior estimates of these parameters using StarBeast3 (Figure 1).

Figure 1. Pipeline of 5 steps implemented by Experimenter package in BEAST 2 that assists in simulation studies to verify correctness of the implementation. (1) Set up XML for desired model and sample from prior. (2) Generate (MCMC) analysis for each of the samples (support for multiple alignments). (3) Run the analyses using StarBeast3 package in BEAST2. (4) Use loganalyser to summarise trace files. (5) Run CoverageCalculator to summarise coverage of parameters. Source: https://github.com/rbouckaert/DeveloperManual.git

We evaluated a strict and relaxed clock model, across varying tree sizes ( 4 species: 12 taxa; 16 species: 48 taxa), and multiple genes (10, 50, 100, and 200). With 100 independent runs, we estimated the coverage of the true value by the 95% highest probability density (HPD) estimates for various parameters in the model (Figure 2) and its newly developed efficient MCMC operators.

Well-calibrated simulation study analysing nS = 16 species, nG = 48 taxa, and k = 50 genes. One hundred simulations were performed to recover the coverage between "true" simulated values and their estimates under the posterior distribution. Vertical lines represent 95% highest posterior density (HPD) intervals of parameters. Each line represents a single simulation and is colored blue when the true value was contained within the 95% interval, or red otherwise. The top of each plot shows the coverage of each parameter (i.e., the number of MCMC simulations for which the "true" parameter value was contained within the 95% HPD). This result was coherent when we tested 100 and 200 genes, respectively.

Conclusion
Our results show all coverage observed is in the expected range, from 90 to 99 inclusive, suggesting the correct implementation of StarBeast3 for all experiments performed. Furthermore, these experiments evidence that starbeast3 is suitable for multispecies coalescent inference on large datasets (100+ genes).
