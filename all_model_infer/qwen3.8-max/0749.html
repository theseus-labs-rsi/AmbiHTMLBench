要有三个交点则必是如右所示, 考场中可用零点存在定理说明一下, 两函数在 $(0, 1)$ 上有一个交点 $x_0$。

由题知:

$g(x_1) = g(x_0) = f(x_0) = f(x_2)$

$e^{x_1} - x_1 = e^{x_0} - x_0 = -\ln x_0 = x_2 - \ln x_2 \cdots *$

$x_1 < 0, 0 < x_0 < 1, x_2 > 1$

$e^{x_1} - x_1 = e^{x_0} - \ln x_0$; $x_1 - \ln x_0 = e^{x_0} - \ln e^{x_1}$, $e^{x_1} > 1$

即 $g(x_1) = g(\ln x_0)$, $x_1, \ln x_0 < 0 \Rightarrow x_1 = \ln x_0$; 同理 $f(x_2) = f(e^{x_0}) \Rightarrow x_2 = e^{x_0}$

$x_1 + x_2 = \ln x_0 + e^{x_0} = 2x_0$ 由 (*) 式可得。
