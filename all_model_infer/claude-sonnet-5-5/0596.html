§4-3 体内物质的运输
血液循环系统 {
血液 心脏 血管

一、血液（约为体重的7%~8%）

1. 血液 {
血浆(55%) { 水、无机盐、葡萄糖和蛋白质等 运载血细胞，运输养料和废物
血细胞(45%) {
红细胞 白细胞 血小板
—若失血超过体内血量的30%，就会危及生命

2. 红细胞
(1)特点：没有细胞核，呈两面凹的圆盘状 增加表面积，摄氧量
(2)数量：正常男性平均约为500万个/mm³
正常女性平均约为420万个/mm³
(3)功能：运输氧和部分二氧化碳
(4)血红蛋白的特性：在氧浓度高的地方容易与氧结合，在氧浓度低的地方容易与氧分离

3. 白细胞
(1)特点：数量少，有细胞核，体积大，有变形性
(2)数量：一般在4000~10000个/mm³血液范围内波动
(3)功能：吞噬侵入人体内的细菌，保护人体免受感染
(4)功能??? 在体内防御和保护机能，主要是能做变形运动和吞噬运动，并有游离养能
(数量)[5红细胞数量比约为1:600]但种类多

4. 血小板
(1)特点：形状不规则，无细胞核，很小
直径2~4μm，体积只有红细胞1/4，是血液中最小的有形成分
(2)数量：正常成人约为15~30万个/mm³
(3)功能：加速血液凝固，防止大量出血及阻止细菌入侵

5. 人体血细胞数量变化及症状
血细胞若多目减少，就是贫血
白细胞若数目增多，就是身体有炎症
血小板若数目减少，不能凝血

6. 血细胞的寿命
血细胞都有一定寿命：红细胞寿命约为120天，大约60天后红细胞更接一半，红骨髓具有造血功能
