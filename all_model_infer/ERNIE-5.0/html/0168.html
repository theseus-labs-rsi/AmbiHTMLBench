坚定信心，打开改革发展新天地。要向广袤乡村要一份答案。四川把县域作为城乡融合发展的重要载体，推动资源要素在城乡间双向流动。
2月14日，四川2025年新春第一季度重大项目现场推进活动举行。2月14日，四川“新春第一课”聚焦高质量发展。
从机器人到人工智能，从低空经济到航空航天，四川省委十二届四次全会提出，要因地制宜发展新质生产力，加快建设现代化产业体系。

这个“2.5亿”意味着什么？

本报记者 谷业凯
我国有14亿多人口，超4亿中等收入群体，人均GDP突破1.2万美元。这“2.5亿”是谁？
看到这个问题，我首先想到了DeepSeek。它在全球范围内引发了广泛关注，让世界看到了中国人工智能的潜力。
这个“2.5亿”是我国网民规模。截至2024年12月，我国网民规模达11.08亿人，较2023年12月增长1608万人。
这“2.5亿”网民，是互联网普及率提升的直接体现。我国互联网普及率达78.6%，较2023年12月提升1.3个百分点。
这“2.5亿”网民，也是数字经济发展的坚实基础。网络零售额、在线服务消费等持续增长。
这“2.5亿”网民，更是中国式现代化的参与者、建设者、受益者。

2月17日，习近平总书记在民营企业座谈会上发表重要讲话，强调“党和国家对民营经济发展的基本方针政策，已经纳入中国特色社会主义制度体系，将一以贯之坚持和落实，不能变，也不会变”。

民营经济发展前景广阔 大有可为——习近平总书记在民营企业座谈会上重要讲话鼓舞人心、催人奋进

本报记者 刘志强 高 乔 王 石 杉
2月17日，习近平总书记出席民营企业座谈会并发表重要讲话，强调新时代新征程民营经济发展前景广阔、大有可为，广大民营企业和民营企业家大显身手正当其时。
当前，我国民营经济已经形成相当的规模、占有很重的分量。民营企业数量占企业总数90%以上，民营企业税收贡献占税收总额50%以上，民营企业发明专利占发明专利总数70%以上，民营企业就业贡献占城镇就业80%以上。
习近平总书记的重要讲话，让广大民营企业家倍感振奋、深受鼓舞。大家表示，要坚定信心，专心致志做强做优做大企业，为推进中国式现代化作出新的更大贡献。

韩正会见国际奥委会主席巴赫

新华社北京2月18日电
2月18日，国家副主席韩正在北京会见国际奥委会主席巴赫。
韩正表示，中国政府高度重视体育事业发展，积极支持国际奥委会工作。中方愿同国际奥委会一道，弘扬奥林匹克精神，推动国际体育事业发展，为构建人类命运共同体作出贡献。
巴赫表示，国际奥委会高度重视同中国的合作，愿同中方加强沟通协作，共同推动奥林匹克运动发展。
