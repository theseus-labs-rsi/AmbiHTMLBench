$A, B$ 分别是复数 $z_1, z_2$ 在复平面内对应的点，$O$ 是原点，若 $|z_1 + z_2| = |z_1 - z_2|$，则三角形 $AOB$ 一定是 B.
  • A. 等腰三角形
  • B. 直角三角形
  • C. 等边三角形
  • D. 等腰直角三角形
由复数的几何意义得： $\overrightarrow{OA}, \overrightarrow{OB}$ 表示 $z_1, z_2$ $\because |z_1 + z_2| = |z_1 - z_2|$ $\therefore$ 由平行四边形加减法得 以 $OA, OB$ 为邻边所作的平行四边形的对角线相等 $\therefore$ 此平行四边形为矩形 $\therefore \triangle OAB$ 为直角三角形
已知 $i$ 为虚数单位，则 $i + i^2 + i^3 + \dots + i^{2019}$ 等于 D.
  • A. $i$
  • B. $1$
  • C. $-i$
  • D. $-1$
$i + i^2 + i^3 + \dots + i^{2019}$ $= i + i^2 + i^3 + \dots + i^{2016} + i^{2017} + i^{2018} + i^{2019}$ $\because$ 每四项为0，即每四项和为0 $\therefore$ 原式 $= i + i^2 + i^3$ $= -1$
若复数 $z$ 满足 $(3-4i)z = |4+3i|$，则 $z$ 的虚部为 B.
  • A. $-4$
  • B. $-\frac{4}{5}$
  • C. $-4i$
  • D. $-\frac{4}{5}i$
$\because (3-4i)z = |4+3i|$ $\therefore z = \frac{|4+3i|}{3-4i} = \frac{5}{3-4i}$ $\rightarrow$ 先求出 $z$ $= \frac{5(3+4i)}{(3-4i)(3+4i)}$ $\rightarrow$ 分母、分子同时 $3-4i$ 的共轭复数 $= \frac{3}{5} + \frac{4}{5}i$ $\therefore z$ 的虚部为 $\frac{4}{5}$
