第九章 · 无讼

“讼师”向“律师”的称呼改变，意味着礼治社会向法治社会的转变。

当社会结构和思想观念未能适应法治的时候，贸然推行法治下乡，一方面会破坏原有的礼治秩序，另一方面还不能建立起有效的法治秩序，使人们对“法治”产生抵触。

第十章 · 无为政治

皇权（横暴权力）受到小农经济的限制，长期无法进行大规模工程，所以会采用“无为”的方式来养成。

研究权力主要从两方面着眼。

  • 社会冲突 → 横暴权力：在上下有别的权力统治下，人们达到了休战状态中的临时平衡，但这不是冲突的消弭。
  • 社会合作 → 同意权力：每个人为了维持自己的生活状态，不得不做好自己的分内工作，同时要求别人做好他们的分内工作，这就产生了权利和义务。
