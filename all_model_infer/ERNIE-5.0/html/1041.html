用暗示的积极力量养出优秀孩子

学习上，让孩子体验一个个小成功

✖ 你磨蹭半天了，没写几个字，再磨下去就别睡了
✓ 越早完成作业，休息的时间就越多！
✖ 这么简单的题都不会做？
✓ 这道题你觉得难，不太会是吗？
✖ 赶紧写作业，一点都不自觉
✓ 你很少忘记写作业的，如果需要帮助就告诉我。
✖ 你这孩子怎么这么犟呢，你要听话
✓ 你可以说“不”，但我想听听你的理由理解你。
✖ 你怎么这么烦人呢，就不能安静一会儿吗？
✓ 你自己先去玩一会，妈妈忙完就马上找你。
✖ 勇敢点，这有什么的啊？
✓ 我相信你行的，再试试看，我陪着你
✖ 快点走，再拖拖拉拉你就别出去了。
✓ 我们来比一比，看谁更快出门。
