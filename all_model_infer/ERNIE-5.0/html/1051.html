教学过程：

工人师傅要在一条长 3000 米的道路一旁架设电线杆，计划每隔 50 米架设一根（两端都要架设），一共需要多少根电线杆？

生：这个问题属于植树问题，路线杆相当于树，相邻两根电线杆之间的距离相当于间隔长度，属于“两端都要栽”的情况。

1. 引入

师：我们解决过植树问题中的问题，第一节课要解决两端不栽电线杆，一共需要架设多少根电线杆？

生：只需要 16 根电线杆。

师：现在大家再来估一估一下，这个问题一定是植树问题吗？什么样的问题一定是植树问题呢？

生：两端都栽的问题属于植树问题。

2. 探究

师：我们通过观察身边事物，像路灯、树木、架设电线杆等都要考虑点数和段数之间的关系问题都属于植树问题。

【评析】教师的练习设计遵循少而精的特点，体现数学教学的高效。

3. 巩固

师：通过这节课学习了植树问题，你有什么收获呢？

生：我知道了植树问题的三种情况中棵数和间隔数之间的关系，两端都要栽时，棵数=间隔数+1；一端栽一端不栽时，棵数=间隔数；两端都不栽时，棵数=间隔数-1。

4. 总结

生：我知道植树问题研究的就是点的数量和段数之间的关系。

生：遇到复杂的问题时，我们可以通过化繁为简的思想来解决。

师：通过这节课的学习，同学们不仅掌握了植树问题中棵数和间隔数之间的关系，还学会了画图、一一对应、化繁为简等研究问题的方法。希望同学们以后能运用这些方法解决生活中更多的实际问题。

【评析】《数学课程标准（2022 年版）》强调不仅要关注学生数学学习结果，还要关注学生数学学习过程。

架电线杆时，不仅要和学生共同提取已知要点，而且引导学生回顾学习过程，使学生在总结、反思中意识到，学习最重要的不是记忆公式，而是掌握解决问题的策略与方法，培养学生的应用意识。

【分析】植树问题是一个典型的数学模型，具有很高的数学思维含量和很强的现实背景。在教学中要凸显学生的主体地位，给学生留出足够的时间和空间，让学生经历从实际问题中抽象出数学模型的过程，从而积累活动经验，感悟数学思想。

1. “数形结合”，构建数学模型。

《数学课程标准（2022 年版）》中指出：“要注重对内容进行结构化设计，整合发展学生数学核心素养的课程目标。”教师在研读教材时，不仅要关注本节课深度的知识，更要关注本节课的发展脉络及蕴含的价值。本节课植树问题作为“两端都要栽”“一端栽一端不栽”“两端都不栽”三种情况，虽然多个问题呈现不同的知识，但本质都是不变的，同时所运用的探究方法也是不变的。教师将线型图这种数学模型，引领学生根据基本的思想方法“画图”“一一对应”让学生举一反三地思考植树问题，教师通过沟通了解植树问题和以前学过的除法问题解决的联系，提升解决问题的能力，积累数学活动经验。

2. 从“具体”到“一般”，深化理解。

植树问题的学习重点不是“求结果”，而是让学生经历从特殊到一般的思维过程。为了帮助学生更好地理解问题，教师从学生熟悉的生活经验引入，引导学生将实际问题抽象成数学问题，利用画图、一一对应等策略解决问题。通过让学生用自己的方法去解决问题，对知识有了更深刻的理解。核心问题：从现实生活中发现并提出问题，经历“分析问题—寻找策略—解决问题—反思评价”的过程，感受数学思想方法在解决问题过程中的作用，积累数学活动经验。

3. 从“问题”到“应用”，提升应用意识。

课程标准指出要以“生本”为核心理念，让学生逐步适应社会发展需要的核心素养。本节课教师从“两端都要栽”的问题入手，让学生从尝试解决到寻求答案，经历了“画图—一一对应—总结规律”的自主探究过程。学生在自主探究中发现画图解决问题的好处，用一对一对应解决了植树问题的变式题，通过不断的追问，引导学生自觉联想到其他的两种情况，再运用数形结合的思想方法变得水到渠成。从“问题”到“方法”，这个过程不是教师的灌输和讲授，而是以“生本”的自主探究式的学习方式，是贴近学生的、最自然的学习路径。
