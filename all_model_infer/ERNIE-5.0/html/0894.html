4. 教师观 (教师要求):

角色:
  • 教师是学生学习的促进者
  • 教育教学的研究者 (复杂性)
  • 课程的开发者和建设者
  • 开发者 无 → 有    建设者 有 → 优
  • 社区型开放教师
行为:
尊重 (对问题学生不打不骂) 赞赏 (表扬)
  • 帮助引导 (与是学生学习的促进者同意)
  • 自我反思
  • 合作
身心

5. 学生观:

学生是发展中的人:
  • 学生的发展是有规律的.
    我们要按照学生的身心发展规律进行教育.
  • 学生是具有巨大的发展潜能的.
    我们要肯定，每个学生都会有进步.
  • 学生是发展过程中的人 (容错)
    学生的身心发展尚未成熟，要允许学生犯错.
  • 学生的发展是全面的发展.
学生是独特的人.
  • 与机器人比 → 有情绪，思想.
    学生是完整的人.
  • 与其他人比 → 学生有自身的独特性.
  • 与成人比 → 学生之间有巨大的差异.
