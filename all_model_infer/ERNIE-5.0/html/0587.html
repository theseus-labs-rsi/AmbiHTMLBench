501 $\chi_{[0,1]}(|\mathbf{x}|)(1-|\mathbf{x}|^2)^\delta$ $\frac{\Gamma(\delta+1)}{\pi^\delta |\xi|^\gamma} J_\gamma(2\pi |\xi|)$ $2^\delta \frac{\Gamma(\delta+1)}{|\omega|^\gamma} J_\gamma(|\omega|)$ $\frac{\Gamma(\delta+1)}{\pi^\delta} \left| \frac{\omega}{2\pi} \right|^{-\gamma} J_\gamma(|\omega|)$ Here, $\gamma = \frac{n}{2} + \delta$.
The function $\chi_{[0,1]}$ is the indicator function of the interval $[0, 1]$. The function $\Gamma(x)$ is the gamma function. The function $J_{\frac{n}{2}+\delta}$ is a Bessel function of the first kind, with order $\frac{n}{2} + \delta$. Taking $n=2$ and $\delta=0$ produces 402.$^{[82]}$
502 $|\mathbf{x}|^{-\alpha}, \quad 0 < \text{Re } \alpha < n$ $\frac{(2\pi)^\alpha}{c_{n,\alpha}} |\xi|^{-(n-\alpha)}$ $\frac{(2\pi)^{\frac{n}{2}}}{c_{n,\alpha}} |\omega|^{-(n-\alpha)}$ $\frac{(2\pi)^n}{c_{n,\alpha}} |\omega|^{-(n-\alpha)}$ See Riesz potential, where the constant is given by $c_{n,\alpha} = \pi^{\frac{n}{2}} 2^\alpha \Gamma\left(\frac{\alpha}{2}\right) / \Gamma\left(\frac{n-\alpha}{2}\right)$. The formula also holds for all $\alpha \neq n, n+2, \dots$ by analytic continuation, but then the function and its Fourier transforms need to be understood as suitably regularized tempered distributions (see Homogeneous distribution).$^{[note 10]}$
503 $\frac{1}{|\sigma| (2\pi)^{\frac{n}{2}}} e^{-\frac{1}{2} \mathbf{x}^T \sigma^{-T} \sigma^{-1} \mathbf{x}}$ $e^{-2\pi^2 \xi^T \sigma \sigma^T \xi}$ $(2\pi)^{-\frac{n}{2}} e^{-\frac{1}{2} \omega^T \sigma \sigma^T \omega}$ $e^{-\frac{1}{2} \omega^T \sigma \sigma^T \omega}$ This is the formula for a multivariate normal distribution normalized to 1 with a mean of 0. Bold variables are vectors or matrices. Following the notation of the aforementioned page, $\Sigma = \sigma \sigma^T$ and $\Sigma^{-1} = \sigma^{-T} \sigma^{-1}$
