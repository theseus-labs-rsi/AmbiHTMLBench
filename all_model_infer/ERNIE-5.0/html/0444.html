1. 填一填。
(1) $\frac{3}{5} + \frac{2}{3} = \frac{2}{3} + (\frac{3}{5})$，应用了 (加法交换) 律。
(2) $\frac{1}{5} + \frac{3}{8} + \frac{5}{8} = \frac{1}{5} + (\frac{3}{8} + \frac{5}{8})$，应用了 (加法结合) 律。
(3) $1 - \frac{4}{15} - \frac{7}{15} = 1 - (\frac{4}{15} + \frac{7}{15})$，应用了 (减法的性质)。
2. 在 ○ 里填上适当的运算符号。
(1) $\frac{3}{8} \bigcirc \frac{4}{9} \bigcirc \frac{5}{8} = \frac{4}{9} + (\frac{3}{8} \bigcirc \frac{5}{8})$
Handwritten: + + +

(2) $\frac{3}{8} \bigcirc \frac{4}{9} \bigcirc \frac{3}{8} = \frac{4}{9} + (\frac{3}{8} \bigcirc \frac{3}{8})$
Handwritten: + + +

(3) $\frac{8}{9} \bigcirc \frac{5}{9} \bigcirc \frac{4}{7} = \frac{8}{9} - (\frac{5}{9} \bigcirc \frac{4}{7})$
Handwritten: - - +

(4) $\frac{8}{9} \bigcirc \frac{4}{7} \bigcirc \frac{8}{9} = \frac{8}{9} - (\frac{4}{7} \bigcirc \frac{8}{9})$
Handwritten: - + -
3. 选择合适的方法进行计算。
(1) $\frac{3}{4} + \frac{1}{3} + \frac{5}{6}$
$= \frac{9}{12} + \frac{4}{12} + \frac{10}{12}$
$= \frac{23}{12}$
$= 1\frac{11}{12}$
(2) $\frac{5}{8} + (\frac{3}{4} - \frac{1}{2})$
$= \frac{5}{8} + (\frac{6}{8} - \frac{4}{8})$
$= \frac{5}{8} + \frac{2}{8}$
$= \frac{7}{8}$
(3) $1 - \frac{1}{6} - \frac{1}{4}$
$= 1 - (\frac{1}{6} + \frac{1}{4})$
$= 1 - (\frac{2}{12} + \frac{3}{12})$
$= 1 - \frac{5}{12}$
$= \frac{7}{12}$
(4) $\frac{7}{9} + \frac{5}{7} + \frac{5}{9}$
$= \frac{7}{9} + \frac{5}{9} + \frac{5}{7}$
$= \frac{12}{9} + \frac{5}{7}$
$= \frac{4}{3} + \frac{5}{7}$
$= \frac{28}{21} + \frac{15}{21}$
$= \frac{43}{21}$
(5) $\frac{3}{4} + \frac{1}{5} - \frac{1}{20}$
$= 1 - (\frac{1}{5} + \frac{1}{20})$
$= 1 - (\frac{4}{20} + \frac{1}{20})$
$= 1 - \frac{5}{20}$
$= 1 - \frac{1}{4}$
$= \frac{3}{4}$
(6) $\frac{5}{8} + \frac{3}{8} + \frac{3}{14} - \frac{3}{14}$
$= (\frac{5}{8} + \frac{3}{8}) + (\frac{3}{14} - \frac{3}{14})$
$= 1 + 0$
$= 1$

6. 有一个装满水的水池，若第一次放出一池水的 $\frac{1}{8}$，第二次放出一池水的 $\frac{1}{4}$，第三次又注入一池水的 $\frac{1}{7}$。现在池子里的水占池子的几分之几？
$1 - \frac{3}{8} - \frac{1}{4} + \frac{1}{7} = \frac{3}{56}$
