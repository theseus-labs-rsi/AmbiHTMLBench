宝宝米粉添加指南

1 不同阶段宝宝米粉选择

每个阶段宝宝对辅食的营养需求会存在差异，根据宝宝生长发育选择分段米粉，为宝宝提供更精准更科学的营养。

第一阶段：宝宝能坐立起
[Image: Box 1]
——这时添加1段米粉。
1段米粉含铁高，粉质细腻好吸收。适应后可添加蔬菜泥和水果泥。
第二阶段：宝宝萌牙期
[Image: Box 2]
——这时可添加2段米粉。
2段米粉在1段基础上添加一些蔬果颗粒，用以启蒙咀嚼另外维生素D可促进钙吸收。
第三阶段：宝宝会爬行
[Image: Box 3]
——这时可添加3段米粉。
3段米粉相比2段米粉添加了多种更大的果蔬颗粒，以此强化锻炼宝宝咀嚼！并且多种食材搭配，口感丰富，更能激发宝宝的味蕾，让宝宝爱上吃
2 宝宝吃米粉的好处
  1. Fe
    补充乳类中不足的营养
    添加米粉等辅食，可及时补充母乳中铁和维生素D的不足。
  2. Yes
    训练宝宝的吞咽能力
    宝宝可以从糊状、细软的食品开始，逐步适应、接受成年人吃的固体食物。
  3. 3
    为断奶做准备
    辅食逐渐取代母乳，让宝宝逐渐由吸食乳类变为用成年人的方式咀嚼食物。
  4. 4
    开启宝宝智力
    添加辅食可以给予宝宝多种刺激，进而达到启迪智力的目的。
  5. 5
    训练咀嚼能力
    及时添加辅食有利于训练宝宝的咀嚼功能，有利于颌骨的发育和牙齿的萌出。
3 如何挑选宝宝米粉
  1. 选择品牌产品
    建议选择大品牌、口碑好的产品，其质量相对而言更有保障。
  2. 查看产品标识
    看一看正常商品应该有的标识是否齐全，宝宝产品特有的标志以及说明是否印在包装上。
  3. 查阅营养成分表
    查看所含的具体营养成分及其含量是否在合理范围内。
  4. 查看包装说明
    查看外包装上是否有提示性说明，比如断奶期补充食物等。
  5. 看颜色与气味
    正常呈米白色，大小均匀，香味纯正，散发米粉固有的香味，且无其他异味。
  6. 看组织形态和冲调性
    其性状松散无结块，冲调后为泥糊状。
