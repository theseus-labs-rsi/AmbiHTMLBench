✓ 8、“be going to”

be going to 表打算/准备/计划将要做。表可能/有必然，通过现象推；使用它，要注意，疑问形式 be 提前。否定句更简单，not 放在 be 后边；to 之后，动原形，be 的形式看人称。

✓ 9、一般疑问句

一般疑问句，变起来很容易，be 动词往前提，变否定也容易，be 后 not 加上去，针对 I 来提问，I 变 you 是常理

✓ 10、特殊疑问句

特殊疑问句变起来有程序：第一，确定疑问词，第二，代替划线语，第三，将疑问词放句首，疑问词后加一般疑问句，语序倒置要牢记。

✓ 11、祈使句

表命令和禁止 通常主语被省 原形动词放句首 否定 don't 就可以 Let's 也是一句型，生活中常常用，祈使句不礼貌，使用分寸要把好

12、过去式

标准过去加 ed，少量不规则分别记，am,is 对 was，第二人称复数 are 变 were,have,has 用 had. do 和 does 变 did.

13、规则动词过去式构成

过去式构成，一般词尾把 ed 加。如果词尾有 e，直接加 d 就可以。“辅音字母+y”在词尾，变 y 为加 ed。“一辅重闭“作尾巴，双写之后 ed 加。

14、There be 句型

There be 句型有规律，疑问否定都用 be，be 词可有不同形式，变疑问 be 提前，变否定也容易，be 后 not 填上去，some 用于肯定句，否定疑问用
