【考点 1】长度、时间及其测量

难度 ★ 考频 ☆☆☆
单位换算和估测 $1km=10^3m$ ; $1dm=10^{-1}m$ ; $1cm=10^{-2}m$ ; $1mm=10^{-3}m$ ; $1\mu m=10^{-6}m$ ; $1nm=10^{-9}m$ 一支新的 2B 铅笔的长度约为 18cm；
随着音乐做一套眼保健操用时约为 4min；
物理书的长度是 252mm；
他自己的身高是 16.7dm；
人的心脏正常跳动一次的时间约为 0.8s。
刻度尺的读数 测量结果由数字和单位组成，其中数字部分由准确值加上一位估计值组成 若刻度尺的分度值是 1mm，那读数应为 4.30cm 或 4.31cm，最后一位“0”、“1”是估读值。
长度测量的特殊方法 累积法 测一张邮票的厚度时，可先测 50 张的厚度。
化曲为直法 用棉线测弯曲工件的长度。
平移法（配合法） 用游标卡尺测量螺母直径；测身高用的卡尺。
比例法 利用竹竿和影子长度测量建筑物高度。

【考点 2】机械运动

难度 ★★ 考频 ☆☆☆☆
参照物 要描述一个物体是运动的还是静止的，要先选定一个标准物体作参照，这个选定的标准物体叫参照物。 “两岸青山相对出”选取船为参照物；
人站在下面水流很快的桥上头晕，是因为人选河水为参照物；
月亮在云中穿行选云层为参照物；
通常我们说“风力 4 级”是以地面为参照物。
运动和静止的相对性 物体是静止的还是运动的，与所选的参照物有关 地球同步卫星选地面为参照物时是静止的，选太阳为参照物时是运动的；
起飞的飞机中的乘客相对大地是运动的，相对飞机是静止的。
