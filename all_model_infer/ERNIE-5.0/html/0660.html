韩语学习笔记

1. A는 B가 아닙니다 (A is not B)

(저는) 학생이 아닙니다.
我不是学生。

이것은 무엇입니까? (这是什么？)
이것은 가방입니다. (这是包。)
이것은 가방이 아닙니다. (这不是包。)

2. A는 B의 C입니다 (A is B's C)

A는 B가 아닙니다.
A不是B。

이것은 무엇입니까? (这是什么？)
이것은 책입니다. (这是书。)
이것은 책이 아닙니다. (这不是书。)

3. "-이"的发音规则

① 当"-이"位于词首并遇到"1时，发[-i]
이사 (移徙) - 이발 (理发)
② 当"-이"位于词中或遇到其他辅音时，发[i]
주이다 (注意) - 의자 (椅子)
③ 当"-이"作为"的"意思时，发[e]
내 책의 (我的书) - 후에 (以后)
