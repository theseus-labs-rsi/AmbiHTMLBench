因护照有效期问题，包价出境游终止
旅行社未尽提醒义务，消费者如何维权？

杨俊泽：暑假期间，我计划去日本旅游，便在某旅行社报名参加了包价出境游。出发前，我突然发现护照有效期不足6个月，无法出境。我只能中止行程。我想咨询：因护照有效期问题无法完成包价出境游，旅行社是否应退还我尚未发生的费用？我应如何维护自身合法权益？

浙江读者 王先生

王先生：随着出境游持续走热，旅行社的包价团队游或“私家团”等产品，成为不少人的热门选择。当旅游者与旅行社签订包价旅游合同后，双方便形成了服务合同关系，服务提供方应当按照合同约定，提供符合标准和质量要求的旅游服务。

由于护照有效期问题终止旅行，旅行社在未履行告知义务的行为，您可与旅行社进行协商，要求其退还您预先支付的团费。协商不成的情况下，您可通过仲裁、诉讼等方式来维护自身合法权益。

可主张旅行社未尽到必要的审查提示义务

《中华人民共和国旅游法》第六十二条规定：“订立包价旅游合同时，旅行社应当向旅游者告知下列事项：……”

具体而言，旅行社应当告知旅游者的注意事项主要包括以下几个方面：

  1. （一）旅游者适合参加旅游活动的情形；
  2. （二）旅游活动中的安全注意事项；
  3. （三）旅行社依法可以减免收费的信息；
  4. （四）旅游者应当注意的旅游目的地相关法律、法规和风俗习惯、宗教禁忌，依照中国法律规定不宜参加的活动；
  5. （五）法律、法规规定的其他应当告知的事项。

在包价旅游合同履行中，遇有前款规定事项的，旅行社也应当告知旅游者。

旅行社作为专业旅游服务企业，在组织包价旅游时，应当知晓旅游目的地的各项政策要求，并对必要的注意与告知义务，在出发前及时进行清晰明确的告知。若旅行社在与您签订服务合同后，未对其提供的护照电子版进行审核，而实际上，您所持有的护照有效期确实不符合要求，导致您无法出行，您可主张旅行社未尽到审查提示义务，进行维权。

维权方式

依据《中华人民共和国出境入境管理法》第五十五条、第二百五十六条等规定，您享有合同解除权，可以要求解除与旅行社签订的包价旅游合同，要求旅行社退还尚未发生的费用。若协商不成，您可向旅游主管部门投诉，或者向人民法院提起诉讼，要求旅行社承担相应的违约责任。

此外，根据《旅游法》第七十条规定：“旅行社不履行包价旅游合同义务或者履行合同义务不符合约定的，应当依法承担继续履行、采取补救措施或者赔偿损失等违约责任；旅游者在旅游行程中未经导游或者领队许可，故意脱离团队，遭受人身损害、财产损失，请求旅行社赔偿损失的，人民法院应予支持。”

  1. （一）双方协商；
  2. （二）向消费者协会、旅游投诉受理机构或者有关调解组织申请调解；
  3. （三）根据与旅游经营者达成的仲裁协议提请仲裁机构仲裁；
  4. （四）向人民法院提起诉讼。

建议您先与旅行社积极协商解除与费用退还等问题。若协商不成，您可申请调解、提请仲裁或提起诉讼等方式解决。

律师提醒

建议您妥善保留好相关的证据材料，如您的护照信息、旅游合同文件、与旅行社的沟通记录等，以证明您无法出行系旅行社在履行中存在不当行为。在维权过程中，请保持冷静和理智，若您对维权的具体法律程序不太熟悉，建议您寻求专业律师的帮助。

中企承建项目让博茨瓦纳民众喝上放心水
[Image: Water pump project in Botswana]

“再也不用喝咸水了！”博茨瓦纳卡塔曼区的村民生活迎来了巨大改变。历时18个月的建设，由中国土木工程集团承建的卡塔曼区供水项目于2023年下半年正式通水，给当地带来了干净的自来水。约1.7万村民因此受益。

该地区属热带草原气候，村民特巴说，在来到这里之前，缺水、缺电、缺医是主要困扰当地民众的难题。“以前我们只能喝咸水，现在终于有了优质的淡水。”

博茨瓦纳位于纳米比亚、津巴布韦和南非之间，大部分地区属热带草原气候，年降水量较少且分布不均，缺水是制约当地经济社会发展的重要因素之一。由于该区域地域辽阔，村民居住分散，项目投资大、周期长，如何让供水项目惠及更多民众，是项目建设团队面临的主要难题之一。

博茨瓦纳供水项目涉及供水主管网和配套管网建设，包括14公里的供水管网铺设、11座水塔建设、4个增压泵站的土建及设备安装、3个蓄水池土建、1座一体化水处理厂的设计与施工。此外，还包括两座行政办公楼、1座员工宿舍以及给水、机械、暖通等配套工程。

项目执行经理杨伟民介绍，该项目每天的水处理能力目前为4000立方米，可满足3万多人用水需求。自正式投入使用以来，已累计为该地区提供了14万立方米的自来水。

谈及这个项目，莫扎比对未来村庄发展充满希望。他说：“中国建筑公司给我们带来了特别好的项目，现在的水太珍贵了，生活方便了很多，村里每个人都很感激。”

在特巴家里，新安装的水龙头位于院子一角，一拧开水龙头，清澈的自来水便流了出来。“原来的水是咸的，现在是甜的！”他兴奋地说。

杨伟民介绍，该项目的启动和竣工先后带动了当地经济社会发展。项目高峰期在场人员达到400人，为当地提供了临时就业岗位，培养了一批当地就业。此外，工程建设期间，为当地餐饮、住宿、交通等行业创造了当地经济发展。

“为这一供水项目工作的团队就是当地的一分子。”他说，“中国公司的到来不仅改善了我们的生活，还提高了我们的技能水平。”

（新华社哈博罗内5月3日电 记者滕军）

“肖像”中“肖”的读音

杜老师：

有些人把“肖像”的“肖”读成xiāo，请问正确读法是什么？谢谢。

北京读者 王女士

王先生：

在1957年出版的《国语辞典》中，“肖像”的“肖”注音为xiào。在当下使用的工具书中，如《现代汉语词典》等，“肖”的注音为xiào。其中“肖”的意思是“像”，如“肖像”指以某一个人为主体的画像或照片等。“肖”也指“像”，如“惟妙惟肖”。由于现代人对于“肖”和“削”的混淆，有人把“肖像”读成xiāo，这是不对的。“肖”在姓氏中读xiāo，如“肖姓”。但在“肖像”一词中，应读xiào。

（北京语言大学教授 杜永道）

农药，是指用于预防、控制危害农业、林业的病、虫、草、鼠和其他有害生物以及有目的地调节植物、昆虫生长的化学合成或者来源于生物、其他天然物质的一种物质或者几种物质的混合物及其制剂。
