本地人排队都要吃重庆美食

✓
马房湾66号江湖菜★★★★★

非常出名的重庆江湖菜，味道超级地道，推荐江湖第一蒸，辣子鸡，招牌血旺等，环境是七
八十年代怀旧风，集颜值与味道于一身的江湖菜

重庆江湖菜 top1
✓
洋马儿火锅★★★★★

一家藏得很深的火锅，很正宗的九宫格火锅，九宫格上面放着鹌鹑蛋，虾滑、毛肚超级好吃

✓
君之薇火锅★★★★★

这是一家藏在半山腰上的火锅店已经有20多年历史了，味道还是那么霸道，重点是还便宜，
性价比超高，冰汤圆和卤味系列的菜是我的最爱，他们家包子还超好吃

✓
六指烧烤★★★★★

烧烤店也能排队排到心累，碳火烤出来的烧烤真的太香了，特别喜欢吃烤豆干，里面放一些
他们家的泡萝卜，好吃到哭

✓
沈姐烤鱼★★★★★

很正宗的重庆万州烤鱼，就在重庆大学B区，烤鱼有多种味道，最爱吃的还是香辣味，性
价比很高，一大条鱼才几十块钱的样子

✓
熨斗糕老烧饼★★★★★

在较场口的梯坎上，在繁华的大都市中，买上一只只卖5毛钱的熨斗糕满满的童年回忆，Q
弹软糯，烧饼也很好吃，价格也很感人！

✓
翠江楼三鲜砂锅米线★★★★★

虽然比较远，但是贵的是程度一般，到这里安静，淳朴！藏在大山上25年的砂锅米线；
一排队也可同时煮很多砂锅，每一位料都非常丰富，鲜香四溢！

✓
食济楼重庆特产严选超市★★★★★

重庆买特产的好去处，是连锁店，正规不会被坑，他们家的上下城火锅底料还不错，作为本
地人都经常买来煮火锅

✓
老院子肥肠鸡★★★

这家店在老居民楼的坝坝里，每天人都是爆满，他们家的肥肠鸡非常入味，滴着油的肥肠柔
初又有弹性，口感很不错
