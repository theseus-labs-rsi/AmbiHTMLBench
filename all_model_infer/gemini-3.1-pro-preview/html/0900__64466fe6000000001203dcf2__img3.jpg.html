4. 一个西瓜，第一次吃了它的 $\frac{1}{3}$，第二次吃了它的 $\frac{2}{5}$。
(1) 两次一共吃了它的几分之几？
$\color{#d32f2f}{\frac{1}{3} + \frac{2}{5} = \frac{11}{15}}$
(2) 这个西瓜还剩下几分之几？
$\color{#d32f2f}{1 - \frac{11}{15} = \frac{4}{15}}$

$\color{#d32f2f}{\frac{3}{8} + \frac{3}{5} = \frac{39}{40}}$
