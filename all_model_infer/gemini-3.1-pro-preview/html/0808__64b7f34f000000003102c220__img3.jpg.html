乡土社会的基本性质
① 乡土本色
  • [种地谋生] → [不流动] → 外在：不需要文字 → 没有文字环境
  • [聚居是常态] → 不流动的社会：熟悉 → 信任 → 规矩、礼俗 → 彼此信任 → 不用法
  • [人与人：礼俗、规矩、人与人是信任的]
  • [土地平等的继承原则] → 家的原则
  • 文字：语言、表意 → 配合当时语境 → 结合当面动作等 → 面对面交流 → 极少使用文字
② 文字下乡
  • 不可否认：个别人的言语之争
  • 乡土社会：面对面交流 → 不需要文字
  • 时间间隔：由于是定居，生活定型 → 语言足够，传情达意无碍 → 不需要文字
  • 空间间隔：人与人都在一处 → 面对面沟通 → 语言足够
  • 结论：乡土社会的特殊环境，使得文字下乡显得多余或不适用。
③ 再论文字下乡
  • 个人的今昔之隔 → 时间间隔 → 记忆 (个人的今昔之隔)
  • 社会性的今昔之隔 → 传统 (世代相继) → 乡土社会：生活定型 → 语言足够，传情达意无碍 → 不需要文字
  • 结论：在乡土社会中，文字是多余的。

乡土社会的社会秩序
① 礼治秩序
  • 论述重点：秩序 —— 维持社会秩序所用的不同力量
  • 概念或概念：人治 · 法治 · 礼治 → 人治与法治的区别
  • 比较维度：乡土社会 —— 现代社会 (在维持社会秩序时所用力量)
  • • 礼是社会公认合式的行为规范，维持礼治的规范是传统。
    • 传统效力更大，人们以对传统致敬，礼治影响人们生活。
    • 乡土社会向现代社会变迁过程中，原有对诉讼问题的观念与现代法治存在碰撞。
② 无讼
  • 留存其间，因之使现代的司法不能切合乡土社会的内在秩序。
  • 论述重点：法律 —— 不同秩序模式下冲突的解决方式，法治推行与传统礼治的冲突。
  • 比较维度：乡土社会 —— 现代社会
  • ① 现代社会是法治社会，讲个人权利，权利不可侵犯。
    ② 乡土社会是礼治社会，注重修身克己，打官司是可羞之事，表示教化不够，司法处在乡下人的眼光中成了包庇作恶的机构。
乡土社会的权力结构
① 无为政治
  • 论述重点：治理 —— 两种权力模式下的国家治理方式
  • 横暴权力：从社会冲突着眼，权力表现在社会不同群体阶层间由不平等发生。
  • 同意权力：从社会合作着眼，发生的共同授予的权力 → 基础是社会契约。
② 长老统治 —— 血缘和地缘
  • 论述重点：第三种权力：更为复杂的 → 是压迫性的权力与教化性权力的交织。
  • 中国政治现态：教化权力、文化·政治 → 社缘：血缘社会是稳定的。
  • 教化权力：发生于社会新旧交替的过程中，是教化性的权力，其社会地位不随个人选择。
  • • 社会变迁快，长老权力不为所忍，反对。
    • 社会变迁慢，长者权力稳固，缺乏“领袖”英雄，识别稳定。
③ 名实的分离 —— 从欲望到需要
  • 论述重点：表与里 —— 不同权力模式下如何应对。
    心理机制 欲望 → 紧张 → 动作 → 满足 → 愉悦
  • 时势权力：发生于激烈、剧烈的社会变迁中。社会冲突、不同社会模式的内在矛盾激化。
  • 动力基础：欲望，需要，经验与认知。乡土社会 —— 现代社会的转变。
