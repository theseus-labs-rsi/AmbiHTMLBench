(1) 若 $C=\frac{2\pi}{3}$, 求 $B$;

(2) 求 $\frac{a^2+b^2}{c^2}$ 的最小值.

【解析】 $\displaystyle \frac{\sin 2B}{1+\cos 2B}=\frac{2\sin B\cos B}{2\cos^2 B}=\frac{\sin B}{\cos B}=\frac{\cos A}{1+\sin A}$

$\Rightarrow \sin B + \sin B\sin A = \cos B\cos A$

$\Rightarrow \sin B = \cos B\cos A - \sin B\sin A = \cos(B+A) = -\cos C$

$\because B, C \in (0, \pi), \therefore \sin B > 0 \Rightarrow \cos C < 0, C > \frac{\pi}{2}, B \in \left(0, \frac{\pi}{2}\right)$.

$\sin B = \sin\left(C-\frac{\pi}{2}\right) \Rightarrow B = C-\frac{\pi}{2}$ 或 $B+C-\frac{\pi}{2} = \pi$(舍)

(1) $B = C-\frac{\pi}{2} = \frac{\pi}{6}$

(2) 因为我们有角的关系,我们将边化为角: $A=\pi-B-C=\frac{\pi}{2}-2B$; $C=\frac{\pi}{2}+B$

由正弦定理: $\displaystyle \frac{a^2+b^2}{c^2} = \frac{\sin^2 A + \sin^2 B}{\sin^2 C} \Rightarrow \frac{\cos^2 2B + \sin^2 B}{\cos^2 B} = \frac{(2\cos^2 B-1)^2+1-\cos^2 B}{\cos^2 B}$

令 $x=\cos^2 B$, $x \in (0,1)$

$\displaystyle \frac{a^2+b^2}{c^2} = \frac{(2x-1)^2+1-x}{x} = \frac{4x^2-5x+2}{x} = 4x+\frac{2}{x}-5 \geqslant 2\sqrt{8}-5 = 4\sqrt{2}-5$

如图, 直三棱柱 $ABC-A_1B_1C_1$ 的体积为 $4$, $\triangle A_1BC$ 的面积为 $2\sqrt{2}$.

(1) 求 $A$ 到平面 $A_1BC$ 的距离;

(2) 设 $D$ 为 $A_1C$ 的中点, $AA_1=AB$, 平面 $A_1BC \perp$ 平面 $ABB_1A_1$, 求二面角 $A-BD-C$ 的正弦值.

【解析】(1)等体积法:设 $A$ 到平面 $A_1BC$ 的距离为 $h$

$\displaystyle V_{A_1-ABC} = V_{A-A_1BC} \Rightarrow \frac{1}{3} \cdot 4 = \frac{1}{3} S_{\triangle A_1BC} \cdot h \Rightarrow h=\sqrt{2}$

(2)大家应该都能看出 $BC \perp$ 面 $ABB_1A_1$,但就是很多人没证出来.

建系的这个说明是必要的. 取 $A_1B$ 中点 $M$,连 $MD$

$AA_1=AB, AA_1 \perp AB \Rightarrow AM \perp A_1B$, 又平面 $A_1BC \perp$ 平面 $A_1ABB_1A_1$,则 $AM \perp$ 面 $A_1BC, BC \subset$ 面 $A_1BC \Rightarrow AM \perp BC$, 又 $AA_1 \perp BC \Rightarrow BC \perp$ 面 $ABB_1A_1 \Rightarrow BC \perp AB$(省略了一点步骤,大家考场中不要省)

作 $MN \perp BD$,连 $AN$, 易证 $\angle MNA$ 即为 $A_1-BD-A$ 的平面角,也是二面角 $A-BD-C$ 的补角, 两者正弦值相等.

图中各关系都易求, $BD=\sqrt{3}$, 等面积法求 $\displaystyle MN=\frac{\sqrt{2}}{\sqrt{3}}$, $\displaystyle AN=\frac{2\sqrt{2}}{\sqrt{3}}$

$\displaystyle \sin \angle MNA = \frac{AM}{AN} = \frac{\sqrt{3}}{2}$
