中办印发《全国党员教育培训工作规划(2024—2028年)》
会心不远，要登绝顶莫辞劳
——写在“十四五”规划收官之年
本报评论员

新华社北京2月27日电 近日，中共中央办公厅印发了《全国党员教育培训工作规划（2024—2028年）》，并发出通知，要求各地区各部门结合实际认真贯彻落实。

《全国党员教育培训工作规划（2024—2028年）》主要内容如下：

为深入学习贯彻习近平新时代中国特色社会主义思想，贯彻落实党的二十大和二十届二中、三中全会精神，深刻领悟“两个确立”的决定性意义，增强“四个意识”、坚定“四个自信”、做到“两个维护”，根据《中国共产党章程》和《中国共产党党员教育管理工作条例》等制定本规划。党员教育培训工作，以习近平新时代中国特色社会主义思想为指导，全面贯彻党的二十大精神，以坚定信仰、增强党性、提高素质为重点，坚持思想建党、理论强党、从严治党，坚持围绕中心、服务大局，坚持分类指导、按需施教，坚持联系实际、继承创新，坚持简便易行、务实管用，不断增强针对性和实效性，为全面建设社会主义现代化国家、全面推进中华民族伟大复兴提供坚强保证。

一、总体要求

（一）指导思想。坚持以习近平新时代中国特色社会主义思想为指导，全面贯彻党的二十大精神，认真落实新时代党的建设总要求和新时代党的组织路线，以学习贯彻习近平新时代中国特色社会主义思想为首要任务，以坚定理想信念宗旨为根本，以提高政治素质和履职能力为重点，健全完善党员教育培训体系，增强教育培训的系统性、针对性、有效性，引导广大党员自觉做习近平新时代中国特色社会主义思想的坚定信仰者和忠实实践者，为强国建设、民族复兴伟业作出新的更大贡献。

（二）基本原则。

1. 坚持政治统领。把政治建设摆在首位，把旗帜鲜明讲政治贯穿党员教育培训全过程各方面，突出政治功能，强化政治训练，教育引导广大党员深刻领悟“两个确立”的决定性意义，增强“四个意识”、坚定“四个自信”、做到“两个维护”，不断提高政治判断力、政治领悟力、政治执行力。

2. 坚持思想引领。把用习近平新时代中国特色社会主义思想武装全党作为党员教育培训的首要任务，引导党员读原著、学原文、悟原理，深刻领会其核心要义、精神实质、丰富内涵、实践要求，掌握贯穿其中的立场观点方法，自觉用以观察分析形势、谋划推动工作。

3. 坚持需求导向。聚焦党员队伍特点和实际需要，精准施教、因材施教，分类分级开展培训，增强教育培训的吸引力和感染力，激发党员参加学习的内生动力。

4. 坚持融合创新。统筹整合各类教育培训资源，创新方式方法，运用信息化手段，线上线下相结合，推动党员教育培训与中心工作深度融合，实现常态化长效化。

5. 坚持从严从实。弘扬理论联系实际的马克思主义学风，防止形式主义、官僚主义，确保教育培训质量效果。

（三）主要目标。经过5年持续努力，基本形成系统完备、科学规范、运行有效的党员教育培训体系，党员教育培训工作质量显著提升，广大党员理想信念更加坚定、党性观念进一步增强、能力素质全面提升，先锋模范作用充分发挥。

二、坚持不懈用习近平新时代中国特色社会主义思想凝心铸魂

（一）把学习贯彻习近平新时代中国特色社会主义思想作为首要任务。组织党员原原本本学习研读党的二十大报告和党章，学习《习近平著作选读》《习近平谈治国理政》等重要著作，跟进学习习近平总书记最新重要讲话和重要指示批示精神，深刻领会其核心要义、精神实质、丰富内涵和实践要求。把学习贯彻习近平新时代中国特色社会主义思想同学习马克思主义基本原理贯通起来，同学习党史、新中国史、改革开放史、社会主义发展史联系起来，同新时代党和国家事业取得的历史性成就、发生的历史性变革结合起来，不断深化理解认识、把握规律特点、增强行动自觉。

（二）建立健全党的创新理论学习长效机制。完善党委（党组）理论学习中心组学习制度，发挥领学促学作用。严格落实“三会一课”、主题党日等制度，把习近平新时代中国特色社会主义思想作为必修课。用好红色教育资源，开展体验式教学。加强青年党员、流动党员、离退休党员等群体学习教育，确保全覆盖、无遗漏。

新华社北京2月27日电 中共中央总书记、国家主席、中央军委主席习近平近日对国家级经济技术开发区工作作出重要指示指出，建设国家级经济技术开发区是我国推进改革开放的重要举措。40年来，国家级经济技术开发区坚持扩大开放，深化改革创新，艰苦奋斗、锐意进取，为开放型经济新体制建设、区域协调发展和产业高质量发展作出了积极贡献。

习近平强调，新征程上，国家级经济技术开发区要深入贯彻落实党的二十大和二十届二中、三中全会精神，坚持党的全面领导，贯彻新发展理念，紧紧围绕推进中国式现代化，不断激发创新活力和内生动能，积极参与构建新发展格局，以高水平对外开放促进深层次改革、高质量发展。要勇当改革开放的排头兵，因地制宜发展新质生产力，扎实推进产业集群建设，积极开展国际产业合作，加快建设现代化产业体系。要巩固提升先进制造业产业基础，推动产业高端化、绿色化、数字化，打造数字产业、未来产业，因地制宜发展新质生产力。要着力优化营商环境，完善市场经济基础制度，依法保护外商投资权益，吸引更多全球优质要素集聚，在进一步全面深化改革开放中走在前列、当好示范。

招商局质量发展之路

“净零碳”是绿色发展必答之题，也是企业高质量发展的必然选择。近年来，招商局集团深入践行“双碳”战略，将绿色低碳理念融入企业发展血脉，以科技创新驱动绿色转型，走出了一条具有招商局特色的“净零碳”发展之路。

从绿色港口到低碳航运，从新能源产业到绿色金融，招商局集团全产业链布局“净零碳”赛道。旗下招商港口率先打造全球领先的自动化集装箱码头，通过岸电设施、光伏发电等技术应用，大幅降低碳排放；招商轮船加快船舶动力系统升级改造，推广使用清洁能源燃料；招商蛇口在园区开发建设中广泛应用绿色建筑标准，打造低碳社区样板……

更难能可贵的是，招商局集团将ESG（环境、社会和公司治理）理念深度融入企业治理体系，建立了完善的碳数据管理平台和信息披露机制，定期发布可持续发展报告，接受社会监督。这种透明开放的态度，不仅增强了投资者信心，也为行业树立了标杆。

面向未来，招商局集团将继续以“净零碳”为目标引领，加大绿色技术研发投入，深化产业链协同减排，努力成为行业绿色转型的先行者和示范者，为中国经济高质量发展注入源源不断的绿色动能。

广西着力向海图强 开放发展

广西新闻网南宁2月27日电 （记者 邓星朋）记者从广西壮族自治区发展改革委获悉：今年一季度，广西沿海三市（北海、钦州、防城港）GDP增速均高于全区平均水平，向海经济生产总值突破4000亿元，同比增长7.2%，海洋经济成为拉动全区经济增长的重要引擎。

近年来，广西深入实施“向海图强”战略，依托西部陆海新通道建设机遇，大力发展临港工业、现代物流、滨海旅游等产业。北部湾港货物吞吐量跻身全球港口30强，钦州石化产业园、防城港钢铁基地等重大项目相继投产，形成了以石化、冶金、电子信息、装备制造为主导的现代海洋产业体系。

自治区海洋局局长蒋和生表示：“我们将继续深耕蓝色国土，做强做优海洋经济，努力在服务共建‘一带一路’、推动西部陆海新通道建设中展现新作为。”

宁夏加快建设新型能源体系

本报银川2月27日电 （记者 李 蕊）宁夏回族自治区能源局日前发布数据显示：截至2024年底，宁夏新能源装机容量达到3500万千瓦，占电力总装机的51%，首次超过煤电装机，标志着宁夏新型能源体系建设取得重大进展。

作为全国首个新能源综合示范区，宁夏充分利用丰富的风光资源，大力推进沙漠、戈壁、荒漠地区大型风电光伏基地建设。目前，已建成千万千瓦级新能源基地，“宁电入湘”特高压直流工程稳定运行，每年可向湖南输送清洁电量400亿千瓦时。

自治区发改委副主任王汉文介绍：“我们正在加快构建清洁低碳、安全高效的能源体系，力争到2030年非化石能源消费比重达到25%左右，为国家能源安全和‘双碳’目标实现贡献宁夏力量。”
