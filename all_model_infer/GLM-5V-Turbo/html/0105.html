古诗三首
绝 句
[唐]⑥ 杜甫
迟日①江山丽，
春风花草香。
泥融②飞燕子，
沙暖睡鸳鸯③。
huì chóng chūn jiāng wǎn jǐng
惠崇春江晚景④
[宋]⑦ 苏 轼
竹外桃花三两枝，
春江水暖鸭先知。
蒌蒿⑤满地芦芽短，
正是河豚⑥欲上时。
注释
①【迟日】春天白天渐长，所以说“迟日”。
②【泥融】这里指泥土湿润。
③【鸳鸯】一种鸟，常在水边嬉戏，雄鸟与雌鸟常常结对生活。
重点
注释
①惠崇是北宋名僧，能诗善画。这首诗是苏轼为惠崇的画作《春江晚景》所写的题画诗。
②【蒌蒿】草名，荻草。
③【河豚】一种有毒的鱼。
