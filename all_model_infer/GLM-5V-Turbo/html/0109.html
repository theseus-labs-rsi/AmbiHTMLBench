微题时，要有这个意识。
★ 28. 就某个词或者某个句子设问题，不用猜词。第一条，文章主旨！不用去研究这个词什么意思，把文章主旨即可，全文主旨和段落主旨(前者更重要)。
★ 29. 接着 28 条说，不管什么题型，上面说的还是其他别的题型，很绝对的话：反主为主的肯定对，前提是你能够确定它是主旨。所以，文章读不太懂，但能把那作者要表达的意思即可。
★ 30. 注意中心句(即题眼)和前后句子之间的关系。是接着说的，还是转折关系。这里出现的话，要把握和前后句子之间的关系。是并列关系的，可以从这些句子里找同义词。是转折关系的，就通过转折关系句子里面的关键词的相反意思来判断，前提是在你读不懂的情况下。
★ 31. 凡是举例的，都是为了证明观点的，那么，这个观点(中心句)，一般来说，会在举例之前就表达了，但有时候也在举例之后。总之，作者举你例说明的这个观点，你一定要找出来。
★ 32. 排除2个选项以后，选和文章主旨相关的选项即可，不知道主旨就把关键词。
★ 33. 词汇题的正确答案，挂柱稳赢在原文的该处附近(就是那个同义替换词)。原文这附近的句子，是并列关系或者解释说明的，就从这些句子的关键词的相近意思去把握。是转折关系的，就从关键词的相反意思去把握。总之，你要找的就是那个关键词。和30条一起理解吧。。
★ 34. 如果原文中出现 “A is B & C”。若某一题，选项中出现了 B 没 C ，或者只出现 C 没 B，肯定错，直接排除。可能你会问了，问时出现 B 和 C 吧？目前还没出现过这种情况。。注意，这里说的 B 和 C，是单词或者短语。。这是干扰项的特点之一。实际情况是，这个句子不是题眼。
