因护照有效期问题，包价出境游行程终止——
旅行社未尽提醒义务，消费者如何维权？
编辑你好： 浙江读者 王先生

我计划今年春节带家人去东南亚旅游，便在某在线旅游平台预订了境外游地接服务并支付相关费用。然而，在出发前两天我接到通知，称因我的护照有效期不足6个月无法出行。此前，我竟完全不知道护照有效期需超过6个月这一要求。请问，旅行社是否有义务提醒游客注意此类事项？旅行社是否需要承担赔偿责任？对此，我该如何维权？

王先生：

根据你描述的情况，旅行社的行为可能构成违约或服务瑕疵。依据《民法典》第五百七十七条及《旅游法》第七十条规定，若因旅行社未履行合同义务（如未对游客进行充分告知义务）导致你遭受损失，你有权要求其承担相应责任。

至于你提到的护照有效期超出6个月限制，旅行社作为专业服务机构，理应具备更高的注意义务。根据《最高人民法院关于审理旅游纠纷案件适用法律若干问题的规定》，旅行社未履行告知义务造成游客损失的，应当承担相应的赔偿责任。

可主张旅行社承担必要的
举证损失

《中华人民共和国旅游法》第十四条规定：“旅游者在旅游活动中应当遵守社会公共秩序和社会风俗习惯，爱护旅游资源……”同时，旅行社应当按照合同约定提供符合安全标准的旅游服务。

依据民航局、外交部等发布的公告，由于多数国家要求入境旅客护照有效期须在6个月以上，这属于旅游行业普遍知晓的专业知识。作为专业机构，旅行社有义务在签约时主动核查并提示游客确保护照有效期符合目的地国家要求；若其未尽到合理提醒义务，则属于服务瑕疵甚至违约行为。

关于维权建议：首先保留所有沟通记录、支付凭证等证据材料；其次可向当地文旅部门投诉或申请调解；最后可通过诉讼方式追究其违约责任。赔偿范围通常包括已支付但未消费的费用、重新预订产生的差价损失等。

■ 维权方式

依据《中华人民共和国民事诉讼法》第一百二十二条，你可向被告住所地或合同履行地法院提起诉讼。建议优先选择协商或调解途径，以降低维权成本和时间成本。

  1. 函告旅行社要求协商解决后续事宜；
  2. 向旅游行政管理部门投诉举报；
  3. 向消费者协会申请调解；
  4. 向人民法院提起诉讼。

（注）另据《最高人民法院关于审理旅游纠纷案件适用法律若干问题的规定》第十七条，因不可抗力等客观原因导致行程变更的，旅行社不承担赔偿责任，但应协助办理退改签手续。

■ 律师提醒

建议游客在签订旅游合同时仔细阅读条款，特别是关于证件有效期、取消政策等关键内容。对于出境游项目，务必提前确认目的地国家的入境要求，包括但不限于护照有效期、签证类型、疫苗接种证明等文件要求。同时保留好电子版和纸质版合同副本，以便发生争议时作为证据使用。

中企承建项目为博茨瓦纳居民带来放心水
“原来的水是咸的，
现在是甜的！”

“再也不会喝咸水了！”家住加弗拉姆的村民玛利亚·莫尔瓦激动地说。近日，由中国企业承建的博茨瓦纳北马供水项目正式通水，彻底解决了困扰当地居民多年的饮水难题。

该项目于2023年9月开工建设，主要包括新建取水泵站、输水管道及配套净水设施。在建设过程中，中方团队克服了干旱缺水、地质条件复杂等诸多困难，采用先进的水处理技术确保出水水质达到世界卫生组织标准。

据项目负责人介绍，北马地区原有地下水资源矿化度高，口感苦涩且长期饮用不利于健康。新建成的水厂日处理能力达5万立方米，可覆盖周边15个村庄约3万居民。

“以前我们要走很远的路去打井水，现在自来水直接通到了厨房。”村民凯图迈莱笑着说。该项目不仅改善了民生，还为当地创造了200多个就业岗位，培养了一批掌握专业技能的技术工人。

博茨瓦纳水利部部长塔佩特·马西雷出席通水仪式时表示，中国企业的专业精神和高效施工令人印象深刻，该项目是两国共建“一带一路”合作的又一重要成果。

“肖像”中“肖”的读音

杜老师：

我看到有人将“肖像”读作“xiào xiàng”，可是字典里明明标注的是“xiào”，到底哪个是对的？

答：“肖”字确实存在两种读音：

读xiào时，意为相似、像，如“惟妙惟肖”“生肖”；

读xiāo时，主要用于姓氏。

原文：

在1997年出版的《语言文字规范词典》中，“肖像”的“肖”注音为xiào。而在用于姓氏时才读xiāo。因此，“肖像画”“肖像权”中的“肖”均应读四声xiào。例如，新疆维吾尔自治区有个地方叫“肖尔布拉克”，这里的“肖”也是读xiào。

需要特别指出的是，《义务教育常用词表（草案）》将“肖像”归入201个最常用词之一，其中“肖”统一标为xiào。《现代汉语词典》（第7版）同样采用此标准。

值得注意的是，在某些方言区或口语中可能出现变音现象，但在规范普通话教学中应严格遵循字典标准。

简单记忆口诀：“肖”字有两个音，不像生肖读xiào，只有姓肖才读xiāo。肖像照片要记牢，四声才是正确调。

“肖”的古字形从肉小声，本义为骨肉相似，引申为相像、类似之意。故“惟妙惟肖”“酷似”“神似”等词语中的“肖”都表示“像”的意思，自然读xiào而非xiāo。

杜老师语文信箱

四声xiào时，表示“像”；一声xiāo时，仅用于姓氏。
（1）“生肖”的正确读音是shēng xiào（四声）；
（2）“惟妙惟肖”形容描写或模仿得非常逼真生动；
（3）“肖像权”指自然人对自己肖像享有利益并排斥他人侵害的权利。
（4）常见误读：将“肖像”读成xiāo xiàng是错误的，应纠正为xiào xiàng。

鱼灯巡源 点亮古村落

日前，一场别开生面的鱼灯巡游活动在安徽省黄山市歙县溪头镇汪满田村举行。身着传统服饰的村民们手持色彩斑斓的鱼灯穿梭于青石板巷道，吸引众多游客驻足观看。

汪满田鱼灯制作技艺始于南宋，距今已有600多年历史。每盏鱼灯需经过扎架、糊纸、绘彩等十余道工序，最长可达3米。2021年，该民俗被列入国家级非物质文化遗产代表性项目名录。

“我们希望通过这种方式让年轻人了解传统文化。”鱼灯传承人田民秋表示，近年来村里每年都会举办元宵节鱼灯展演活动，参与人数逐年增多。

海关答疑
出口农药产品需要注意啥？
陈先生：
我是农药经销商，想拓展海外业务。听说出口农药有很多特殊规定，能否详细介绍一下具体流程和注意事项？
海关答复：
企业出口农药需重点关注以下环节：
一、资质审核：生产企业须取得农业农村部颁发的农药登记证和生产许可证；
二、包装标识：必须符合联合国GHS标签规范，注明危险公示、成分含量等信息；
三、检验检疫：部分高毒品种需实施产地检验和装运前检验；
四、单证准备：除常规报关资料外，还需提供农药登记证明、毒性分类说明等专项文件。
问：出口农药如何办理商检？
根据《进出口商品检验法》及其实施条例，列入《必须实施检验的进出口商品目录》的农药产品应在报关前向产地海关申报检验。检验内容包括有效成分含量、理化指标、包装安全性等。检验合格后签发《出境货物通关单》，凭以办理出口报关手续。
问：哪些农药禁止出口？
目前我国对滴滴涕、六氯苯、毒杀芬等持久性有机污染物实行全面禁令。此外，根据《鹿特丹公约》事先知情同意程序，某些高毒农药出口前需获得进口国主管部门的书面许可。建议通过国际贸易单一窗口查询最新管制清单。
问：了解产品特性对报关有何帮助？
准确申报商品编码（HS Code）至关重要。不同类别的农药税率差异显著，且涉及不同的监管条件。例如，除草剂通常归入3808.93项下，而杀虫剂多属3808.91。错误归类可能导致通关延误或行政处罚。建议咨询专业报关行或使用海关预裁定服务确认归类意见。
出口报关注意事项
1. 单证一致性：发票、箱单、合同中的品名、数量、金额必须与实物完全相符；
2. 包装合规：液体农药需采用UN标准包装容器，附具危险货物标签；
3. 运输安全：托运时应向承运人如实申报危险特性，选择具备危险化学品运输资质的物流公司；
4. 目的国准入：提前调研进口国农药注册制度，如欧盟要求REACH注册，美国需EPA登记等；
5. 留存档案：妥善保管出口报关单、检验证书等文件至少3年，以备海关稽查。
