三、防御机制

(一)非特异性免疫

  1. 屏障感染：青霉素 链霉素 庆大霉素
  2. 吞噬细胞：脑膜炎奈瑟菌或淋病奈瑟菌与荚膜相关
第四节 荚膜菌属：(E) 常成双排列
一、脑膜炎奈瑟菌：G⁻ 无芽孢 无鞭毛
有荚膜和菌毛 二、流行性脑脊髓膜炎：专性需氧 三、发病机制(M)
病原菌 → 侵入鼻咽部 → 局部炎症 → 入血
↓
菌血症/败血症 → 突破血脑屏障 → 脑膜发炎症状
四、与免疫学
  1. 易感者为G⁻双球菌，内毒素中性粒细胞内
  2. 培养特性：普通培养基需加血液或血清等培养基
    中等量生长，巧克力培养基 巧克力血琼脂平板
  3. 生化反应
    大多数脑膜炎奈瑟菌分解葡萄糖和麦芽糖，不产
    酸不产气与奈瑟菌分类
  4. 5.抵抗力
    • (1)荚膜糖特异性抗原
      对理化因素抵抗力很强
      对干燥 热为消毒剂敏感
    • (2)内毒素是导致败血症休克原因
    • (3)脂寡糖抗原
    • (4)胞膜外层蛋白抗原
血清学鉴定：A B C D H I N X Y Z 等 13个
↓
"致病力最强"

(二)致病症

1.致病物质

  1. (1)荚膜：有抗吞噬作用 能增强细菌侵袭力
  2. (2)菌毛：有助于细菌黏附至呼吸道/皮肤黏膜表面
    和T1步骤入
  3. (3)A群(重要)：破坏IgA，帮助细菌的行进细胞黏膜
  4. (4)脂磷壁酸：是肺炎链球菌M蛋白主要致病物质
  5. (5)外毒素：普遍占90%→上呼吸道炎症
  6. (6)人类是唯一感染源

2.所致疾病

大量繁殖血凝素(增加黏膜通透性)
↓
突破血管出现出血性皮疹
↓
暴发型中毒性休克型主要因
内毒素释放作用于血管内皮细胞DIC
弥漫性血管内凝血肾上腺出血
肾上腺皮质功能衰竭沃-弗综合征
注：对严重病例脑膜炎双球菌进行特异性预防，治疗首选药物为青霉素G，剂量要大，对过敏者选用红霉素
