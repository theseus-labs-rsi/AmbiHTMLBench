31、磷与氧气反应，氧气充足生成五氧化磷，氧气不是生成三氧化磷。
32、白磷分子式为P4，分子晶体，故1mol白磷含有磷原子数目为4NA。
33、Cl2与足量Fe反应，无论铁过量还是不足量，只生成氯化铁，只有溶液中缺才与氯化铁反应生成氯化亚铁。
34、$\text{Al}^{3+} + 3\text{AlO}_2^- + 6\text{H}_2\text{O} = 4\text{Al(OH)}_3 \downarrow$
35、过量二氧化碳通入水玻璃中反应为：
$\text{H}_2\text{O} + 2\text{CO}_2 + \text{Na}_2\text{SiO}_3 = 2\text{NaHCO}_3 + \text{H}_2\text{SiO}_3 \downarrow$ 二氧化碳不过量生成碳酸钠
36、比较半径大小：
(1) 层相同，核大半径小。
(2) 层异，层大半径大。
(3) 核同，价高半径小。例如铁大于二价铁大于三价铁
(4) 电子层结构相同，核电荷数越大，半径越小。
37、C是形成化合物种类最多的元素，单质是自然界中硬度最大的物质元素气态氢化物中氢的质量分数最高的元素。
38、元素气态氧化物和它的氧化物在常温下反应生成该元素单质的是S。这是高中很重要的知识点，也是在验证二氧化硫具有氧化性阴的反应。
$2\text{H}_2\text{S} + \text{SO}_2 = 2\text{H}_2\text{O} + 3\text{S}$
39、元素的气态氢化物和它的最高价氧化物对应的水化物能反应生成盐的元素为N。
40、单质在常温下呈液态的非金属元素为Br。
单质在常温下呈液态的金属元素力：Hg。
41、合金是混合物，性能往往优于其组成的金属，比如：硬度比它的各组分金属硬度大，合金的熔点比它的各组分熔点低。
42、$3\text{Mg} + \text{N}_2 = \text{Mg}_3\text{N}_2$    $2\text{Mg} + \text{CO}_2 = \text{C} + 2\text{MgO}$（条件是点燃，别忘记N2哦，花物质的量算出，如果认为镁与氮气不反应就是错误的）
43、生铁、普通钢、不锈钢含碳量依次降低。生铁：生铁是含碳量大于2%的铁碳合金，钢：钢是含碳量0.04%-2.3%之间的铁碳合金，不锈钢是Fe、C、Cr合金，Fe含量大约为74.6%。
44、明矾净水的原因是利用水解原理，原理是明矾在水中可以电离出易解金离子：$\text{KAl(SO}_4)_2 = \text{K}^+ + \text{Al}^{3+} + 2\text{SO}_4^{2-}$ 而Al3+很容易水解，生成胶状氢氧化铝$\text{Al(OH)}_3$: $\text{Al}^{3+} + 3\text{H}_2\text{O} = \text{Al(OH)}_3$(胶滴)$ + 3\text{H}^+$ 氢氧化铝
