1. A는 B A은/는 B이/가 아닙니다
    (저는) 학생이 아닙니다.
    我不是学生。
    이 사람은 가수가 아닙니다.
    这个人不是歌手。
  2. 2. "-이"的发音规则
    1. ① "当"-이"位于词首并遇到"ㄱ"时，发[-이]"
      의사, 의자
    2. ② "当"-이"位于词中或遇到其他辅音时，[이]"
      수의사, 희망
    3. ③ "当"-이"作为"的"意思时，[에]"
      태양의 후에
  3. 3. A是B的C A은/는 B의 C 입니다.
    [에]
  4. 4. A不是B的C A은/는 B의 C이/가 아닙니다.
