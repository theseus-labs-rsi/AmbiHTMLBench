12～18月龄宝宝的辅食攻略

喂养要点
  • 注重餐饮仪式感，鼓励宝宝和家人共餐感受进餐氛围
  • 开始着重培养宝宝自己用勺子吃饭，鼓励自主进餐
  • 保证充足的奶量，同时开始尝试更多食物形式
  • 如果宝宝对清淡食物非常排斥，可适当加调味品
  • 可以开始尝试蛋清、豆制品、带壳海鲜、坚果等食材

喂养建议
奶类喂养量 每日2次，总计400-600ml
辅食喂养量 每日3次，每次1碗
谷薯类： 各种家常谷类 3/4-1碗
蔬菜类： 各种蔬菜 1/2-2/3碗
水果类： 各种水果 1/2-2/3碗
肉、蛋、鱼、禽、豆类： 蛋、肉、鱼、豆腐类 6-8勺
油类： 每日油10-15g，盐<1.5g
注：以上辅食喂养量并非固定不变，需根据宝宝实际情况和接受度调整。
经典食谱
食谱一：木须肉

用料：猪肉、木耳、黄瓜、鸡蛋、葱、姜、酱油、水

做法：1. 猪肉切小片备用，木耳泡发后撕成小片，用水焯熟备用，黄瓜洗净去皮切成小片备用。

2. 热锅倒食用油，鸡蛋打散后炒熟盛出备用。

3. 锅中下猪肉片炒至变色，再放入木耳、黄瓜、鸡蛋，加少量水，翻炒均匀即可。

食谱二：青椒爆猪肝

用料：青椒、猪肝、葱、姜、蒜、食用油

做法：1. 猪肝洗净后，和葱段、姜片一起放入锅中，加水大火煮沸后捞出猪肝，洗净切成小块丁备用。青椒也洗净切成小块丁备用。

2. 热锅倒食用油，下蒜爆香后捞出。然后放入猪肝丁翻炒至变色后，再放入青椒丁，翻炒至熟即可。

食谱三：土豆胡萝卜软饼

用料：土豆、胡萝卜、面粉、水、食用油

做法：1. 将土豆、胡萝卜洗净去皮后擦丝，再上锅蒸软。

2. 将蒸好的土豆和胡萝卜与面粉混合，加入适量水搅拌成黏稠的糊状。

3. 平底锅内倒食用油，放入一勺面糊小火煎至两面金黄即可。

食谱四：虾球玉米笋

用料：鲜虾、玉米笋、蒜、食用油

做法：1. 鲜虾洗净，抽出虾线，去壳去壳，玉米笋洗净切段，蒜切片备用。

2. 锅中倒入少许食用油，油热后放入蒜片爆香。

3. 放入切好的玉米笋、虾，翻炒片刻后加入少量的水，盖锅盖焖煮3-5分钟。

4. 待汤汁变得浓稠后，再次翻炒几下即可。
