①乡土性 (基层/tmp)

  • 中国社会是乡土性的
  • 特点(一)以农为本 / 土：泥土(种植)
  • 乡下人离不开泥土 → 人口不流动(定居是常态，迁移是变态)
  • 空间不流动 → 聚村而居；原因小农经营、水利合作、安全保卫、土地平等继承(兄弟合居)
  • 村落间：人口流动率小 → 孤立、隔膜
  • (二)不流动 → 地方性：区域间接触少，生活隔离，各自保持孤立的社会圈子
  • (三)熟悉的社会：生于斯、死于斯(终老是乡)；没有陌生人的社会
  • 人与人 relation：规矩 / 礼俗(不是契约)；熟悉产生信任
※ 乡土社会的信用并不是对契约的重视，而是发生于对一种行为的规矩熟悉到不假思索的可靠性。

②文字下乡

  • 乡下人“愚”？—— 知识问题，不是智力问题(“愚”是文盲/不识字)
  • 乡土社会：熟人社会；面对面的社群(直接往来)
  • 文字：发生在人与人在传情达意的过程中受到了空间和时间的阻隔的情境里；文字是间接的说话 → 是“间接接触”的工具，能传的情、达的意却不完全(“文不达意”)
  • 语言：是用声音来表达的象征体系(附着声音/情意)；面对面可用表情、动作、特殊语言(行话)→ “有语言而无文字”

③再论文字下乡

  • 时间阻隔：一是个人的今昔之隔；二是社会的世代之隔
  • 靠记忆与词(语言足够传递世代经验；经验定型的社会，一套固定的表意方式)
  • 乡土社会生活定型(历世不移)→ 所需记忆范围窄，用语言足够代代相传 → 文字不是必需(文字下乡需考虑文字和语言的基础)
差序格局 (团体格局 – 捆柴)
  • ①系维着私人的道德 (道德观念)
  • (1)中国乡土社会的基层结构是一种“差序格局”：一根根私人联系所构成的网络；(2)西洋“团体格局”像捆柴
  • (3)以“己”为中心；范围能伸能缩(像石子投入水中的波纹)→ 自我主义(非个人主义)
  • (4)群己、公私界限：相对性 / 伸缩性；群?>公(?)界限模糊不清
  • (5)道德体系出发点是 “克己复礼”“推己及人”(以“己”作中心，向外推)
  • (6)在差序格局中团体格局缺位；一切普遍的标准并不发生作用 → 要看对象和“自己”的关系
差序格局 · 家族 / 男女有别
  • ①家族(绵续性)：家庭(亲子、生育)是绵续性事业社群；(1)西洋家庭是生育社群、夫妇为主轴、子女配角，政治经济宗教功能由团体担负；(2)中国乡土社会基本社群 = “小家族”(氏族)：单系(父系)扩大、纵轴为主、经营政治经济宗教功能、需绵续 → 夫妇成为配轴
  • 纪律排斥私情 → 夫妇间感情淡漠；同性同龄组合更重要
  • ②男女有别
  • (1)Apollonian / 亚普罗式：认定宇宙安排有完善秩序，人只能接受 → 乡土社会(求稳定)；浮士德式：把冲突看成存在的基础，生命是阻碍的克服(现代社会)
  • (2)男女间生理差别 → 充分了解(“浮士德式”求同)会激动感情、破坏事业；乡土社会求稳 → 男女有别：隔离、男女授受不亲、强调门第，夫妇间不必求精神上的契洽

① 礼治秩序
  • 论述重点秩序 — 维持秩序时所用的力量
  • “人治” vs “法治” vs “礼治”之辨：乡土社会 ≠ 人治社会；也并非西方意义的“法治”
  • 礼治秩序：乡土社会是“礼治”社会 → 无法(≠无秩序)，靠传统维持
  • 礼：社会公认合式(合适)的行为规范；维持礼的规范是传统(累积的经验)
  • 礼治可能的前提：传统可以有效应付生活问题 → 人们对传统有敬畏感，主动服膺于礼(经教化过程成为内在习惯);“克己”
  • 礼 ≠ 文明；也可“野蛮”(如殉葬/缅[?])；礼治 ≠ 人治(人治是个人好恶)，也不同于 automatically 由外在权力推行的“法治” → 靠内在教化(“从心所欲不逾矩”)；一个负责地方[?]秩序的长老说…[?]
② 无讼
  • 论述重点法律 — 维持礼治秩序的力量
  • 乡土社会：调解(评理)模式；打官司丢面子、教化不够；“无讼”理想
  • 现代司法在乡下人眼中成“包庇作恶”(用[?])：礼治秩序被破坏、法治秩序未建成；现行司法与礼治观念不合(差序格局不承认平等个人权利、权利义务[?])；司法处在过渡时期，破坏了原有礼治秩序却又不能有效建立法治秩序
① 长老统治
  • 论述重点治理 — 两种权力模式?[?]下的国家治理模式？(横暴/同意都不足以解释乡土)
  • 长老权力(教化权力)：发生于社会继替的过程(长幼之别)；被教化者学习先于他存在的文化 → 既非横暴(非剥削压迫)也非同意(未成年未取得被同意[?])；乡土社会靠近 “长老统治”：爸爸式[?]权力；文化稳定的区域，长老是权威(年长者对年幼者有强制权力)”

① 血缘和地缘
  • 论述重点第3种权力? / 从血缘到地缘
  • 血缘社会 = 稳定的(缺乏变动)；地缘是血缘的投影[?](空间上的伯父[?])；“生于斯”确定籍贯/血缘
  • 血缘是身份社会的基础；地缘是契约社会的基础(陌生/信用、法律) → 从血缘结合转变到地缘结合是社会性质的转变，也是社会史上的大转变
  • 商业是在血缘之外出现(寄籍/客边[?])；在亲密的血缘社会中商业不能存在
