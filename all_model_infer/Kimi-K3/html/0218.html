1.3  The Real Number System

We now turn to a discussion of the real number system. Rather than constructing the real numbers from the rationals (which can be done in several ways), we shall simply describe their basic properties by means of a set of axioms. The real number system $\mathbb{R}$ is a set with two operations, addition and multiplication, satisfying certain properties which we now list.

Algebraic Properties of $\mathbb{R}$

The real numbers form a field under the operations of addition and multiplication. That is, for all $x, y, z \in \mathbb{R}$:

$(x + y) + z = x + (y + z)$ (1)
$x + y = y + x$ (2)
There exists an element $0 \in \mathbb{R}$ such that $x + 0 = x$ (3)
For each $x \in \mathbb{R}$, there exists $-x \in \mathbb{R}$ such that $x + (-x) = 0$ (4)
$(xy)z = x(yz)$ (5)
$xy = yx$ (6)
There exists an element $1 \in \mathbb{R}$, $1 \neq 0$, such that $x \cdot 1 = x$ (7)
For each $x \neq 0$, there exists $x^{-1}$ such that $x \cdot x^{-1} = 1$ (8)
$x(y + z) = xy + xz$ (9)

Order Properties

The real numbers also possess an order relation $\leq$ satisfying the following properties:

(i) For any $x, y \in \mathbb{R}$, exactly one of the following holds: $x < y$, $x = y$, or $x > y$.

(ii) If $x < y$ and $y < z$, then $x < z$.

(iii) If $x < y$, then $x + z < y + z$ for all $z \in \mathbb{R}$.

(iv) If $x < y$ and $z > 0$, then $xz < yz$.

Supremum and Infimum

Definition 1.3.1.  Let $S$ be a nonempty subset of $\mathbb{R}$.

(a) If there exists $\beta \in \mathbb{R}$ such that $x \leq \beta$ for all $x \in S$, then $S$ is said to be bounded above, and $\beta$ is called an upper bound of $S$.

(b) If there exists $\alpha \in \mathbb{R}$ such that $x \geq \alpha$ for all $x \in S$, then $S$ is said to be bounded below, and $\alpha$ is called a lower bound of $S$.

Definition 1.3.2.  Let $S$ be a nonempty subset of $\mathbb{R}$.

(a) If $S$ is bounded above, then the supremum (or least upper bound) of $S$, denoted $\sup S$, is the unique number $\beta$ satisfying:

(1) $\beta$ is an upper bound of $S$.

(2) If $\gamma$ is any upper bound of $S$, then $\beta \leq \gamma$.

(b) If $S$ is bounded below, then the infimum (or greatest lower bound) of $S$, denoted $\inf S$, is the unique number $\alpha$ satisfying:

(1) $\alpha$ is a lower bound of $S$.

(2) If $\gamma$ is any lower bound of $S$, then $\gamma \leq \alpha$.

The Completeness Axiom

Axiom (Completeness).  Every nonempty subset of $\mathbb{R}$ that is bounded above has a supremum in $\mathbb{R}$.

This axiom is what distinguishes $\mathbb{R}$ from $\mathbb{Q}$. For example, the set $S = \{x \in \mathbb{Q} : x^2 < 2\}$ is bounded above in $\mathbb{Q}$ but has no supremum in $\mathbb{Q}$. In $\mathbb{R}$, however, $\sup S = \sqrt{2}$.

Theorem 1.3.3 (Archimedean Property).  For any $x, y \in \mathbb{R}$ with $x > 0$, there exists a positive integer $n$ such that $nx > y$.

Proof.  Suppose, to the contrary, that the set $A = \{nx : n \in \mathbb{N}\}$ is bounded above. By the completeness axiom, $\alpha = \sup A$ exists. Since $x > 0$, we have $\alpha - x < \alpha$, so $\alpha - x$ is not an upper bound of $A$. Hence there exists $n_0 \in \mathbb{N}$ such that $n_0 x > \alpha - x$, which gives $(n_0 + 1)x > \alpha$. But $(n_0 + 1) \in \mathbb{N}$, so $(n_0 + 1)x \in A$, contradicting that $\alpha$ is an upper bound of $A$. $\blacksquare$

Theorem 1.3.4.  For any $\varepsilon > 0$, there exists a positive integer $N$ such that $\frac{1}{N} < \varepsilon$.

Proof.  Apply the Archimedean Property with $x = 1$ and $y = \frac{1}{\varepsilon}$. Then there exists $N \in \mathbb{N}$ such that $N > \frac{1}{\varepsilon}$, hence $\frac{1}{N} < \varepsilon$. $\blacksquare$

Theorem 1.3.5.  If $S$ is a nonempty subset of $\mathbb{R}$ that is bounded below, then $\inf S$ exists in $\mathbb{R}$.

Proof.  Let $T = \{-x : x \in S\}$. Then $T$ is nonempty and bounded above (since $S$ is bounded below). By the completeness axiom, $\sup T$ exists. One can verify that $\inf S = -\sup T$. $\blacksquare$
