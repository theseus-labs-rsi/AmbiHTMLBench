八、蒸馏操作
[Diagram: 蒸馏装置（左）— 自来水、碎瓷片、温度计、冷凝管、接收器]
[Diagram: 蒸馏装置（右）— 蒸馏烧瓶、温度计、冷凝管、尾接管、锥形瓶]
  1. 1.蒸馏是利用液体的 沸点 不同，分离液体混合物。
  2. 2.碎瓷片的作用： 防止液体暴沸 。
  3. 3.冷凝水 下端口 进，上端口 出，以使冷凝管中充满冷水。
  4. 4.开始馏出的液体为 低沸点的杂质 ，应当弃去。
  5. 5.简易蒸馏装置中长导管的作用是 导气和冷凝 。

  1. 1. 实验1的现象 白磷燃烧，产生大量白烟，气球先膨胀后变瘪 。
  2. 气球的作用是 缓冲压强，防止橡胶塞被冲开 。
  3. 锥形瓶底放一些细沙的目的是 防止锥形瓶炸裂 。反应后，天平是否平衡？ 是 。
  4. 2. 实验2的现象是 铁钉表面出现红色固体，溶液由蓝色变浅绿色 ，
  5. 化学方程式 CuSO4+Fe=FeSO4+Cu 。反应后，天平是否平衡？ 是 。
  6. 3. 实验3结束后，天平是否平衡？ 否 ，原因是 反应生成的CO2逸散到空气中 。
  7. 如何改进装置以验证质量守恒定律 在密闭容器中进行实验 。
  8. 4. 实验4：反应前称量镁条和石棉网质量，反应后称量石棉网和燃烧后得到的产物质量：
  9. ①如果测得反应后质量比反应前质量大，原因 增加了的氧元素的质量 。
  10. ②如果测得反应后质量比反应前质量小，原因 镁条燃烧时形成白烟逸散到空气中 。
