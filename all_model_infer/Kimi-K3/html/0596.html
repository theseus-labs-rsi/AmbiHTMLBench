2. 红细胞
⑴特点：没有细胞核，呈两面凹的圆盘状 增加表面积，携氧量
⑵数量：正常男性平均为500万个/mm³
正常女性平均为420万个/mm³
⑶功能：运输氧和部分二氧化碳
⑷血红蛋白的特点：在氧浓度高的地方容易和氧结合，在氧浓度低的地方容易与氧分离
3. 白细胞
⑴特点：数量少，有细胞核，体积比红细胞大
⑵数量：一般在4000~10000个/mm³血液范围内波动
⑶功能：吞噬侵入人体内的细菌，保护人体免受病患
⑷功能??? 本体防御和保护功能，主要是能做变形运动和吞噬活动，并有免疫机能
（数量少 [与红细胞数量比约为1:600] 但种类多）
4. 血小板
⑴特点：形状不规则，无细胞核，很小
直径约2~4μm，体积仅相当于红细胞的1/3~1/4，是血液中最小的有形成分
⑵数量：正常成人10万~30万个/mm³
⑶功能：加速血液凝固，防止大量出血及阻止细菌入侵
5. 人体血细胞数量变化及症状
红细胞 若数目减少，就是贫血
白细胞 若数目增多，就是身体有炎症
血小板 若数目减少，不能凝血
