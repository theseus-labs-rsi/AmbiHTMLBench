【模型分析】
反比例函数 \( y = \dfrac{k}{x} \)（\( k \neq 0 \)）
k 的符号 k > 0 k < 0
图像
性质 ①x 的取值范围是 x ≠ 0，y 的取值范围是 y ≠ 0
②当 k > 0 时，函数图像两个分支分别在一、三象限，在每个象限内，y 随着 x 增大而减小 		①x 的取值范围是 x ≠ 0，y 的取值范围是 y ≠ 0
