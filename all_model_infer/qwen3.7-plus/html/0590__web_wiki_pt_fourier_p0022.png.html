Alguns pares de transformadas de Fourier
$f(t)$ $F(\omega)$
$\delta(t)$ $1$
$\delta(t - a)$ $e^{-ia\omega}$
$u(t)$ $\pi\delta(\omega) + \dfrac{1}{i\omega}$
$1$ $2\pi\delta(\omega)$
$\operatorname{sgn}(t)$ $\dfrac{2}{i\omega}$
$e^{i\omega_0 t}$ $2\pi\delta(\omega - \omega_0)$
$\cos\omega_0 t$ $\pi(\delta(\omega - \omega_0) + \delta(\omega + \omega_0))$
$\operatorname{sen}\omega_0 t$ $\dfrac{\pi}{i}(\delta(\omega - \omega_0) - \delta(\omega + \omega_0))$
$\operatorname{rect}\!\left(\dfrac{t}{a}\right)$ $|a| \cdot \operatorname{sinc}\!\left(a\dfrac{\omega}{2\pi}\right) = \dfrac{2}{\omega}\operatorname{sen}\!\left(\dfrac{\omega}{a}\right)$
$\cos(\omega_0 t)\,u(t)$ $\dfrac{\pi}{2}(\delta(\omega - \omega_0) + \delta(\omega + \omega_0)) + \dfrac{i\omega}{\omega_0^2 - \omega^2}$
$\operatorname{sen}(\omega_0 t)\,u(t)$ $\dfrac{\pi}{2i}(\delta(\omega - \omega_0) - \delta(\omega + \omega_0)) + \dfrac{\omega^2}{\omega_0^2 - \omega^2}$
$\operatorname{rect}(t/a)\cos(\omega_0 t)$ $a\left(\operatorname{sinc}\dfrac{(\omega - \omega_0)a}{2\pi} + \operatorname{sinc}\dfrac{(\omega + \omega_0)a}{2\pi}\right)$
$\operatorname{sinc}\!\left(\dfrac{t}{a}\right)$ $|a| \cdot \operatorname{rect}\!\left(\dfrac{\omega}{2\pi a}\right)$
$\operatorname{sinc}^2\!\left(\dfrac{t}{a}\right)$ $|a| \cdot \operatorname{tri}\!\left(\dfrac{\omega}{2\pi a}\right)$
$e^{-at}u(t),\;\operatorname{Re}(a) > 0$ $\dfrac{1}{a + i\omega}$
$t^n$ $2\pi i^n \delta^n(\omega)$
$t^{n-1}e^{-at}u(t),\;\operatorname{Re}(a) > 0$ $\dfrac{(n-1)!}{(a + i\omega)^n}$
$e^{-a|t|},\;\operatorname{Re}(a) > 0$ $\dfrac{2a}{a^2 + \omega^2}$
$e^{-\pi t^2}$ $e^{-\frac{\omega^2}{4\pi}}$
$\dfrac{1}{\sqrt{|t|}}$ $\sqrt{\dfrac{2\pi}{|\omega|}}$
$\dfrac{1}{t^2 + a^2}$ $\dfrac{\pi}{a}e^{-a|\omega|}$
$\operatorname{tri}(t)$ $\operatorname{sinc}^2\!\left(\dfrac{\omega}{2\pi}\right)$

Transformadas operacionais

As transformadas de Fourier, assim como as de Laplace, podem ser classificadas como funcionais e operacionais.
