11月龄宝宝的辅食攻略
喂养要点
  • 均衡主副食、菜、肉合理搭配，保证主食摄入量
  • 逐渐为宝宝尝试各种新食物，鼓励他学习进食
  • 辅食中不加盐、糖、酱油等调味品，保持食物的天然味道
  • 如果宝宝进食时用手抓，可给他对侧的食指让他练习
  • 继续定期测量生长曲线，监测辅食添加效果

经典食谱
食谱一青瓜肉泥意面

用料：青瓜、肉、意面、水、食用油、水

做法：1. 青瓜洗净后切片备用。
2. 意面煮熟后放入少量水，搅拌成小肉泥备用。
3. 将意面放入锅中煮熟后捞出，将青瓜下锅翻炒至熟。
4. 向锅中加入水、水、肉泥和青瓜翻炒均匀，加入少许盐即可。

食谱二番茄猪肝

用料：番茄、猪肝

做法：1. 鲜番茄去皮后与猪肝等量切碎备用，把番茄切碎成末。
2. 猪肝洗净后切成末，与番茄碎混合均匀后上锅蒸10分钟即可食用。
3. 将西红柿酱和番茄酱混合均匀，加水大火煮10分钟即可出锅。

食谱三排骨炖萝卜

用料：排骨、萝卜、葱、姜、食用油、水

做法：1. 排骨洗净后和葱、姜一起放入锅中，加水没过排骨，大火煮开后撇去浮沫。
2. 萝卜洗净后切成小块，与排骨同炖至烂熟。
3. 向锅中加入油，放入葱段翻炒出香味，然后将下锅的萝卜至熟至变色，之后把萝卜盛入碗内，浇汤汁10分钟。
4. 将炖好的萝卜块倒入锅中，与排骨翻炒均匀，再加少量水后盖上锅盖，用小火煮至软烂，然后大火收汁即可。

食谱四蛋黄米糊

用料：蛋黄、婴儿营养米粉、水

做法：1. 蛋黄煮熟后用小勺压上碗底打碎，捣成泥后加水搅拌成糊状。
2. 婴儿营养米粉加热水，搅拌成较浓稠的糊状。
3. 将蛋黄糊和米粉糊混合均匀后，倒入模具中上锅蒸约20分钟即可。
