三、防治原则

  • 尿路感染：首季多饮水，或口服呋喃妥因
  • 心内膜炎、脑膜炎：青霉素或氨苄西林与氨基糖苷类联合用药效果较好

第四节 奈瑟菌属

一、脑膜炎奈瑟菌

  • G⁻，肾形双排列
  • 有荚膜和菌毛
  • 无芽胞，无鞭毛
  • 专性需氧
  • 营养要求高
  • 在巧克力色培养基上生长良好
  • 初次分离需要5%~10% CO₂
  • 分解葡萄糖和麦芽糖，不产酸
  • 氧化酶试验阳性

二、致病物质

  1. 荚膜：有抗吞噬作用，能增强细菌的侵袭力
  2. 菌毛：可黏附到鼻咽部黏膜上皮细胞表面
  3. 内毒素：是主要致病物质
  4. 自溶酶：使细菌自溶，释放内毒素

三、所致疾病

  • 流行性脑脊髓膜炎（流脑）
  • 普通型占90%，病程分期：
上呼吸道感染期 → 败血症期 → 脑膜炎期
  • 大量毒素释放入血引起毒血症
  • 入血引起菌血症或败血症
  • 累及脑膜，恶心、呕吐和皮肤瘀点瘀斑

四、免疫性

  • 以体液免疫为主
  • 以IgM、IgG为主
  • 病后免疫力不牢固

五、微生物学检查

标本： 脑脊液、血液、瘀斑渗出液 直接涂片： 革兰阴性双球菌，中性粒细胞内 分离培养： 巧克力色培养基，5%~10% CO₂

六、防治原则

  • 流脑疫苗
  • 治疗：青霉素G，磺胺嘧啶（SD）
淋病奈瑟菌（淋球菌）

一、生物学性状

  • G⁻，肾形双排列，有荚膜和菌毛
  • 营养要求高，在巧克力色培养基上生长
  • 初次分离需5%~10% CO₂
  • 只分解葡萄糖，不分解麦芽糖
  • 氧化酶试验阳性

二、致病物质

  1. 菌毛：黏附尿道/宫颈黏膜上皮细胞
  2. 外膜蛋白：抑制吞噬
  3. IgA蛋白酶：破坏黏膜表面IgA
  4. 内毒素：引起炎症反应

三、所致疾病

  • 通过性接触传播
  • 男性：尿道炎（尿痛、脓性分泌物）
  • 女性：宫颈炎、盆腔炎（症状较轻，易被忽视）
  • 新生儿：结膜炎（脓漏眼）

四、微生物学检查

标本： 尿道/宫颈分泌物 直接涂片： 革兰阴性双球菌，白细胞内 分离培养： 巧克力色培养基，CO₂环境

五、防治原则

  • 加强性卫生教育
  • 治疗：头孢曲松、大观霉素
  • 新生儿预防：出生后用硝酸银滴眼
