证明		 推理 合情推理 归纳推理 由部分具有某种特征推断整体具有某种特征的推理。
类比推理 由一类对象具有的某种特征与另一类对象的某种特征的推理。
演绎推理 根据一般性的真命题（或逻辑规则）导出特殊性命题为真的推理。

数学
归纳法		 数学归纳法是以自然数的归纳公理做为它的理论基础的，因此，数学归纳法的适用范围仅限于与自然数有关的命题。分两步：首先证明当 n 取第一个值 n₀（例如 n₀=1）时结论正确；然后假设当 n=k（k∈N*，k≥n₀）时结论正确，证明当 n=k+1 时结论也正确。
5.不等式与线性规
不等式的
性质		 (1) a > b, b > c ⇒ a > c； 两个实数的顺序关系：
a > b ⇔ a − b > 0
a = b ⇔ a − b = 0
a < b ⇔ a − b < 0
(2) a > b, c > 0 ⇒ ac > bc；a > b, c < 0 ⇒ ac < bc；
(3) a > b ⇒ a + c > b + c；
(4) a > b, c > d ⇒ a + c > b + d； a > b ⇔ 1/a < 1/b 的充要条件是
ab > 0。
(5) a > b > 0, c > d > 0 ⇒ ac > bd；
(6) a > b > 0, n∈N*, n > 1 ⇒ aⁿ > bⁿ, ⁿ√a > ⁿ√b
一元二次
不等式		 解一元二次不等式实际上就是求出对应的一元二次方程的实数根（如果有实数根），再结合对应的函数的图象确定其大于零或者小于零的区间。在含有字母参数的不等式中还要根据参数的不同取值确定方程根的大小以及函数图象的开口方向，从而确定不等式的解集。
基本
不等式		 √ab ≤ (a+b)/2   (a,b ≥ 0) a + b ≥ 2√ab   (a,b > 0)；ab ≤ ((a+b)/2)²   (a,b ∈ R)；2ab/(a+b) ≤ √ab ≤ (a+b)/2
√((a²+b²)/2)   (a,b > 0)；a² + b² ≥ 2ab。
二元一次不
等式组		 二元一次不等式 Ax + By + C > 0 的解集是平面直角坐标系中表示 Ax + By + C = 0 某一侧所有点组成的平面区域。二元一次不等式组的解集是指各个不等式解集所表示的平面区域的公共部分。
简单的
线性规划		 基本
概念		 约束条件 对变量 x, y 的限制条件，如果是 x, y 的一次式，则称线性约束条件
目标函数 求解的最优问题的表达式，如果是 x, y 的一次式，则称线性目标函数。
可行解 满足线性约束条件的解 (x, y) 叫可行解。
可行域 所有可行解组成的集合叫可行域。
最优解 使目标函数取得最大值或最小值的可行解叫最优解。
线性规划 在线性约束条件下求线性目标函数的最大值或者最小值的问题。
